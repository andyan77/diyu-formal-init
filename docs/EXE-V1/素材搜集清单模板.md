# 素材搜集清单模板

> 用途：陪跑开始**之前**交给客户，让他们知道要准备什么。
> 原则：**产品不会凭空知道你们家的事实**。这份清单收的每一项，
> 都是为了让系统"有依据可讲"，而不是让它去编。
> 交付方式：客户按此清单准备 → 由管理端按 [入库操作指引.md](入库操作指引.md) 入库。

---

## 优先级说明

| 级别 | 含义 |
|---|---|
| **必备** | 没有这项，陪跑做不起来 |
| **重要** | 缺了内容会明显变空 |
| **加分** | 有则更好，第一轮可以不给 |

---

## 一、品牌基本盘（必备）

| # | 项 | 说明 | 形式 | 优先级 |
|---|---|---|---|---|
| A1 | 品牌名与定位一句话 | "我们是做什么的，卖给谁" | 文字 | 必备 |
| A2 | 主要客群 | 年龄段、场景、常见处境（不要写"所有女性"） | 文字 | 必备 |
| A3 | 与同类的差别 | 你们真实做得比别人好的 1–2 件事 | 文字 | 必备 |
| A4 | 不能说的话 | 品牌红线：哪些词、哪些说法你们绝不用 | 文字 | 必备 |
| A5 | 语气偏好 | 举一条你们发过的、觉得"很像自己"的内容 | 文字/截图 | 重要 |

## 二、发布账号（必备）

每个要用的号填一份：

| # | 项 | 说明 |
|---|---|---|
| B1 | 账号名与平台 | |
| B2 | 这个号是干什么的 | 与其他号的分工，如"门店现场号"/"总部图文号" |
| B3 | 谁在发 | 岗位（不需要姓名） |
| B4 | 常发什么 | 举 3 条典型内容 |
| B5 | 这个号**不发**什么 | 边界，比其他项更重要 |

## 三、商品（必备，**事实源头**）

> 这是防止系统编造的关键。**没入库的商品，系统就不该写它的具体信息。**

| # | 项 | 说明 | 优先级 |
|---|---|---|---|
| C1 | 货号 / SKU | 唯一标识 | 必备 |
| C2 | 品名 | | 必备 |
| C3 | 价格 | 现价；有活动价请注明生效期 | 必备 |
| C4 | 面料成分 | 照吊牌写，**不要凭印象** | 必备 |
| C5 | 颜色 / 尺码 | 实际在售的 | 必备 |
| C6 | 版型与适穿场景 | "宽松直筒，通勤和日常都行" | 重要 |
| C7 | 工艺 / 细节 | 特殊工艺、做工亮点，须属实 | 重要 |
| C8 | 洗护要点 | | 加分 |
| C9 | 商品图 | 主图 + 细节图，**注明哪张是主视觉** | 必备 |

> ⚠️ **C3/C4 是最容易出事的两项**。价格与成分一旦入错，生成内容会稳定地错下去。
> 入库前请核对吊牌与实际售价。

## 四、门店（有实体店则必备）

| # | 项 | 说明 |
|---|---|---|
| D1 | 门店名与地址 | |
| D2 | 店型 | 街边店 / 商场店 / 展厅 |
| D3 | 主要客流特征 | |
| D4 | 店内实拍 | 陈列、试衣区等 |

## 五、组织素材（重要）

| # | 项 | 说明 |
|---|---|---|
| E1 | 搭配图 / 陈列图 | 注明是哪几件商品的搭配（要能对上货号） |
| E2 | 上身图 | 注明商品货号 |
| E3 | 场景图 | 门店、活动、日常 |

> 素材可以与商品**绑定**（product-bindings）。绑定过的素材，系统才知道
> "这张图对应哪件商品"。**没绑定的图只是普通参考。**

## 六、明确不要提供的东西（红线）

- ❌ **顾客的个人信息**：姓名、电话、微信、住址、照片；
- ❌ **顾客说过的话**，除非已获书面授权并注明；
- ❌ **未经证实的功效断言**："穿了显瘦十斤""三年不变形"；
- ❌ **竞品的负面材料**；
- ❌ **他人版权素材**：网图、他家模特图、未授权字体图。

> 这些不是"最好别给"，是**不能给**。给了系统就会当事实用。

## 交付检查表（入库前逐项打勾）

- [ ] A1–A4 已提供
- [ ] 每个要用的账号都填了 B1–B5
- [ ] 商品清单 C1–C5、C9 齐全，价格与成分已核对吊牌
- [ ] 商品图已注明主视觉
- [ ] 有实体店的已提供 D1–D2
- [ ] 素材已注明对应货号（用于绑定）
- [ ] 已确认不含第六节任一红线项
- [ ] 客户已签 [已知边界卡.md](已知边界卡.md)
