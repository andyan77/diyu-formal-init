# 入库操作指引（管理端流程步骤卡）

> 用途：拿到客户按 [素材搜集清单模板.md](素材搜集清单模板.md) 准备好的材料后，
> 在管理端把它们变成系统能用的依据。
> 入口：`/tenant-admin`（品牌管理登录）；组织素材另有独立入口。
> 执行人：founder 或指名管理员。**陪跑会话期间不做入库**——入库在陪跑之前完成。

---

## 顺序很重要

```
① 组织 → ② 发布账号 → ③ 品牌资料 → ④ 商品 → ⑤ 门店 → ⑥ 组织素材（并绑定商品）→ ⑦ 操作者
```

后面的项要挂到前面的项上，顺序颠倒会返工。

---

## ① 组织

管理端 → 组织。建立客户的组织结构（一般一个门店/部门一个组织）。

- 组织决定后面素材的**可见范围**；
- 只建实际要用的，不要预建。

## ② 发布账号（平台载体）

管理端 → 发布账号。按 [素材搜集清单模板.md](素材搜集清单模板.md) 第二节逐个建。

- 一个"逻辑账号"可以有多个平台载体（抖音/小红书等），**画像挂在逻辑账号上**；
- 建完确认每个账号的定位描述与客户填的 B2 一致；
- 用不到的账号**不要启用**——启用了就会出现在创作端的选择列表里。

## ③ 品牌资料（brand-library）

管理端 → 品牌资料库。把清单第一节的内容逐条入库。

**每条的必填项**：分类、标题、**来源说明**、正文、版本、可见范围。

> **来源说明必须写清楚这条是谁说的、什么时候说的。**
> 这是后续"这句话凭什么这么写"的追溯依据，不是可有可无的备注。

**操作要点**：
- 先用**预览**（preview）看系统怎么理解这条，确认无误再正式入库；
- 资料是**版本化**的：改内容会产生新版本，历史版本保留；
- 不用的条目用**启用/停用**开关关掉，**不要删**——删了追溯就断了。

## ④ 商品（brand-products）

管理端 → 商品。按清单第三节逐个入库，以**货号/SKU** 为唯一键。

**入库前必做的核对**（这一步省不得）：

- [ ] 价格与实际售价一致（有活动价的注明生效期）
- [ ] 面料成分照吊牌写，不是凭印象
- [ ] 颜色尺码是实际在售的
- [ ] 工艺描述属实，不含功效断言

> ⚠️ 商品信息是系统写具体事实时的**唯一合法来源**。这里错一个字，
> 生成内容会稳定地错下去，而且看起来很可信。

**操作要点**：
- 同样先**预览**再入库；
- 商品也是版本化的，改价改款产生新版本；
- 下架商品用**停用**，不要删。

## ⑤ 门店（display-stores）

管理端 → 门店。有实体店才需要。填清单第四节。

## ⑥ 组织素材（organization-materials）**并绑定商品**

素材入口 → 上传图片/素材，然后**逐个绑定到商品货号**。

| 状态 | 系统怎么用 |
|---|---|
| 已绑定商品 | 知道这张图对应哪件商品，可作主视觉/辅助视觉 |
| 未绑定 | 只是"普通参考"，用不上具体商品事实 |

> **绑定是这一步的重点，不是可选项。** 上传了不绑定，等于图白传。

**操作要点**：
- 每件商品至少绑一张**主视觉**；
- 素材同样有启用/停用与版本；
- 上传前再确认一次：不含顾客个人信息、不含他人版权素材。

## ⑦ 操作者

管理端 → 操作者。只建**登记表上有名字的人**。

- 一人一账号，不共用；
- 分配到对应的发布账号；
- 陪跑期内**不新增登记表以外的用户**（硬红线）。

---

## 入库完成后的自检

在创作端用每个要用的账号各走一遍，确认：

- [ ] 能选到这个发布账号
- [ ] 选中后显示的"表达位置"（画像）与客户认可的一致
- [ ] 素材面板里能看到"我的素材"与"组织素材"
- [ ] 至少一件商品能被引用，且价格与成分显示正确
- [ ] 生成一条测试内容，确认没有出现**未入库**的具体事实

> 最后一项如果不通过（系统写了没入库的商品/价格），
> **不要开始陪跑**——先查是哪一步的资料不完整。

---

## 纪律

- **不删除，只停用**：删除会切断追溯链；
- **先预览再入库**：预览是免费的，入错要改版本；
- **来源说明不留空**：留空的资料等于没有依据；
- **陪跑期间不改资料**：改资料属单独授权动作，会影响正在进行的对照观察；
- **不代客户决定内容**：拿不准的项回去问客户，不要自己填一个看起来合理的值。
