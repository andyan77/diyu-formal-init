## 4. 三个最小合同

### 4.1 NarrativeFrame

只写入既有任务快照 JSON，不新增表或迁移。V1 最小字段：

- `frame_version`
- `narrative_mode`
- 冻结用户事实原文及稳定来源 ID
- 允许使用的品牌／商品事实 ID

四种模式：

- `actuality_reflection`：用户给出生活流水账、抱怨、感悟或真人片段；
- `general_observation`：只给开放题材或没有事实承重的安全方向；
- `hypothesis`：明确条件推演；
- `dramatization`：显式选择故事／短剧形式或明确要求情境演绎。

模式依据只来自用户显式形式控制、intake 独立提取并保留的原文跨度和服务端保守默认；不得以
裸关键词表或句型黑名单路由。没有明确演绎要求时不得升级为剧情。

### 4.2 NarrativeBlock

继续复用现有 title、slot、正文、配文和媒体产品，只要求每个最终可见语义块带：

- `block_id`
- `block_type`
- `text`
- `source_refs`
- `scene_ids`

类型只保留 `actuality_source`、`general_observation`、`hypothesis`、`dramatization`。
`actuality_source` 由服务端从冻结原文插入，只做确定性空白、标点和格式整理，Writer 不得
改写、概括、扩展或润色。一般观察不得冒充亲历；假设必须保持可见条件语义；演绎只在显式
演绎模式出现，必须自然可见为演绎且不能绑定真实用户、员工、顾客、品牌案例或门店现场。
所有可见字段必须来自类型化块或可信事实编译，不允许未类型化正文旁路。

### 4.3 ReviewerObservation

Reviewer 可继续使用同一 DeepSeek，但必须是独立请求、独立输入，不复用 Writer 上下文，
也不读取或采信 Writer 自报的 `basis`、`actuality`、`source_refs`。它读取最终完整标题、
导读、正文、口播、字幕、配文、画面、动作、声音和制作提示，以及 NarrativeFrame、
block/scene ID、实际文本和允许事实／资源登记表。

每个 block 与 scene 都必须返回一份观察，至少包含真实存在的精确跨度、人物、关系、动作／
事件、对白、动机、前因结果、时间地点持有物、现实绑定、拍摄资源和不确定性。Reviewer 不
直接裁决 pass；服务端验证跨度、ID、完整覆盖、模式、事实和资源。未知 ID、缺跨度、稀疏
覆盖、格式漂移或语义不确定均失败关闭。

## 5. 内容与资源分离

用户现实原话只授权文字忠实承载，不登记其中的人物、家、店、厨房、物品、照片或声音为拍摄
资源。制作只可使用已登记创作者表达、已选素材、已确认商品资源或本次原创抽象构成。画面关联
NarrativeBlock，但不能反过来成为事实来源，也不得重演或伪装成现实现场。

## 6. 确定性对账与摘要

服务端而非 Reviewer 完成最终裁决：

1. 精确跨度必须存在于最终可见文本；
2. 每个 block／scene 恰好一份完整观察；
3. 真人事实块只能绑定冻结原文；
4. 一般观察不产生具体真人事件绑定；
5. 假设保持条件语义；
6. 演绎有可见提示且不绑定现实履历；
7. 拍摄资源全部在允许登记表；
8. 用户事实来源永不成为拍摄资源。

对被审完整可见对象计算稳定摘要，保存对象必须完全相同。最终审查后不得修改用户可见文本，
纯确定性序列化也必须在摘要之前完成。

## 7. 唯一一次块级修复

首次完整审查失败，只允许替换一个或多个完整失败 NarrativeBlock 及其全部关联画面、动作、
字幕和制作提示；`actuality_source` 不可修改，NarrativeFrame、模式、事实来源和核心用户要求
不可改变。随后重新编译整个成品、重新发起独立 Reviewer、重新执行完整对账与摘要校验。

仍失败则运行失败、版本增量 0、无永久 running；不得第二轮修复、随机重跑或添加
settlement／cascade／stabilize／bind／固定场景回填。

## 8. 自然修改

G7“别讲道理，荒诞一点。”只能改变 `general_observation` 或已有 `dramatization`。
NarrativeFrame、模式、`actuality_source` 原文字节与来源、允许事实集合、账号／品牌／平台和
ContentRole 保持不变。V2 必须实质改变相应表达块；V1 完整可读，前端异步版本读取不得清空
用户已经输入的下一条修改。
