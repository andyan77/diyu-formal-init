## 2. 产品结果

普通交流“今天有点不知道从哪儿开始。”得到自然回复，task/run/version 为 `0/0/0`，Writer
和 Reviewer 均不调用。明确创作“今天不知道发什么，帮我做条小红书。”直接进入创作，不追问
主题、观点、受众或结构。

用户只负责表达生产意图、提供任意颗粒度种子、可选控制及最终事实纠正／采用／发布。系统在

缺少不可替代真实事实时追问一次。

## 3. CreationIntentGate

`CreationCommitment` 是纯应用层、无数据库副作用的版本化不可变对象：

- `gate_version = creation-intent-gate-v1`
- `disposition = not_committed | committed`
- `source = explicit_text | explicit_ui | active_revision`
- `creation_kind = new_content | revision | continuation | recompile`
- `source_turn`
- `intent_span`

Gate 只接受三类可靠承诺：

1. 用户原话中存在正向“创作动作＋交付成果”，且 `intent_span` 是该原话精确子串；
2. 用户主动点击可选“直接生成”，只把当前输入编译成成品，不扩大任何作用域或发布权限；
3. 存在服务端可信任务／版本上下文，用户明确修改、续写或跨平台改编。

模型的 `ready`、proposal 或候选 span 只能作为提议，不能单独授权。Gate 使用最小正向、
版本化语法，不建立题材／人物／经历词表、负面黑名单、G 卡特判、大型 DSL 或聊天状态机。
无法证明承诺时零业务写入、零 Writer／Reviewer 调用，可自然交流并返回轻量“直接生成”动作。

`CreationCommitment` 只写入新任务既有 JSON 快照，不新增表或迁移。旧任务不回填、不伪造，
既有 V1/V2、系列、复制、导出、平台父子版本和可信任务内修改兼容路径继续成立。

## 4. intake 与事务边界

正式顺序固定为：

```text
只读上下文 → Gate → intake → 合法 ready
→ 事务 A：task + running run
→ 事务外：Writer + 独立 Reviewer
→ 成功事务 B：version + completed
→ 失败事务 C：failed run，version 不增加
```

Gate 未授权时 intake 仅服务自然交流；即使恶意 seam 强制 `ready`，也必须保持 task/run/version
`0/0/0`。Gate 授权后 intake 只选 P1—P5、提取逐字事实、选择叙事模式、编译创作计划和判断
不可替代事实缺口。一次事实追问仍为 `0/0/0`，保留原输入和 Commitment；补充后不重新询问
创作职责范围内的主题、观点或结构。

## 5. 门后叙事真实性

以前向实现重新引入最小 `NarrativeFrame`：

- `frame_version`
- `narrative_mode`
- 逐字用户事实及稳定来源 ID
- 允许品牌事实 ID
- 允许商品事实 ID

模式只含 `actuality_reflection`、`general_observation`、`hypothesis`、
`dramatization`。正文使用带 `block_id / block_type / text / source_refs /
linked_scene_ids` 的 `NarrativeBlock`，块类型与四模式对应。

真人事实块由服务端逐字插入，只允许确定性空白或标点整理，Writer 不得改写；现实来源不自动
成为拍摄资源。一般观察可创造观点、比喻、节奏和幽默，但不得冒充现实。假设保持可见条件语气。
演绎只在用户明确选择时启用，须自然标出演绎且不绑定真实用户、员工、顾客或品牌履历。

## 6. Writer、Reviewer 与服务端

Writer 只在冻结 Commitment、Frame 和可信作用域内形成类型化完整成品。同一 DeepSeek 的
Reviewer 使用独立请求和独立输入，不读取或采信 Writer 自报的 basis、actuality、source_refs
或自证结论。

Reviewer 覆盖最终可见标题、正文／口播、字幕、画面、动作、声音、制作提示、发布配文和
AIGC 提醒，并逐 block/scene 返回精确跨度及人物、关系、事件、对白、动机、因果、时间、
地点、持有物、现实绑定、资源与不确定项。

服务端验证精确子串、block/scene 完整覆盖、ID 闭世界、模式、事实和资源；unknown、
uncertain、缺字段、漏审、虚构跨度或模式冲突一律失败。审查前后计算稳定 digest，通过后
不再修改用户可见内容。

## 7. 最多一次完整块级修复

首次失败只允许替换问题 `NarrativeBlock`、所有关联 scene 及字幕、动作、声音和制作提示。
不得修改 Commitment、Frame、模式、真人事实块、事实来源、账号、品牌、平台或任务作用域。
修复后完整渲染、重新独立 Reviewer、重新执行全部服务端对账。仍失败则 run=`failed`、
version=`0`、永久 running=`0`；不进入第二修复、随机重跑、固定成稿或降低事实边界。

## 8. 修改不变量

G7“别讲道理，荒诞一点。”只可改一般观察或演绎块。Commitment、Frame、模式、真人事实块、
来源 ID、品牌／账号／平台／资料范围必须不变；V1 继续可读，V2 成为当前版，V1→V2→V1
可回读。异步完成不得覆盖用户刚刚输入的新内容。
