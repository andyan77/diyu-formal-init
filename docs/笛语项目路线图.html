M7-2A · CLOSED · 最小内容控制面

M7-2A 已于 2026-07-25 由主控终审 CLOSED。CLOSED 只证明软件控制面成立，不证明真实 DeepSeek 内容质量、真实账号画像已由有权主体确认、真实发布、平台流量、企业采用或销售效果——这些连同有界 DeepSeek 真实内容冒烟一并转入 M7-2B。已交付并部署：版本化五轴目录（仓库数据，租户无写入面）、只面向实际启用发布账号的可版本化五段人话画像与控制组织判权、私人创作偏好（租户＋本人双重隔离）、可选且默认收起的创作方向面板、透明品牌转译、本次合法素材选择、冷启动内容机会与轻量计划、未满足需求候选。任务冻结自己的创作条件（含实际使用的 ContentRole 名称与表达边界），修订只重放它。2026-07-25 单一有界修复轮另行硬化：迁移推断出来的账号控制组织记为 inferred、不授予任何维护资格，只有新建时明确指定或租户有权主体一次声明才成立；维护资格检查与版本写入进入同一事务；当前画像指针由数据库约束封死到本账号；私人协作说明进入模型但不进入任何租户可见记录，并提供真正的临时无偏好会话；每轴区分“沿用默认 / 本次选择 / 本次不使用”且空选择不清空已保存默认；计划可「用这条开始」而不建任务；缺人工说明的原件不可勾选并可就地补写；笛语运维获得最小的缺口分类与回告入口。目录对账诚实结果：风格 20/20、题材 55/55、体裁 41/44，缺 3 条已登记为 CAT-SOURCE-GAP-GENRE-001/002/003，不得宣称 119 项全部登记或全部支持。2026-07-25 主控终审极小返工再关闭五处：同一轴优先级写死为「本次明确选择 > 本次自然语言中未被否定的精确标签/别名 > 已保存默认」，保存默认不得压过本次自然要求；为已声明标签/别名增加最小否定语义（不要 / 不想 / 别 / 不用 / 取消，仍不做模糊风格识别、关键词黑名单或第二模型），被拒绝的默认本次不生效且不修改已保存默认；修改接口读取临时无偏好会话请求头，同目标修改只重放快照、跨目标改编显式不读私人偏好；私人协作说明只控制协作与表达取舍，成品中不得引用、复述或解释其原文（提示级约束，未新增审查层）；修复前端交互验证在 Node 20 与 Node 22 的兼容。未证明：有界 DeepSeek 真实内容冒烟未执行；真实笛语账号的控制组织仍是推断值、五段画像仍未由有权主体保存；内容质量、真实发布、平台流量与销售未证明。
