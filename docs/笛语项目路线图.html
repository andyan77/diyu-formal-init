M7-2A · REVIEW · 最小内容控制面

已交付并部署：版本化五轴目录（仓库数据，租户无写入面）、只面向实际启用发布账号的可版本化五段人话画像与控制组织判权、私人创作偏好（租户＋本人双重隔离）、可选且默认收起的创作方向面板、透明品牌转译、本次合法素材选择、冷启动内容机会与轻量计划、未满足需求候选。任务冻结自己的创作条件（含实际使用的 ContentRole 名称与表达边界），修订只重放它。2026-07-27 单一有界修复轮另行硬化：迁移推断出来的账号控制组织记为 inferred、不授予任何维护资格，只有新建时明确指定或租户有权主体一次声明才成立；维护资格检查与版本写入进入同一事务；当前画像指针由数据库约束封死到本账号；私人协作说明进入模型但不进入任何租户可见记录，并提供真正的临时无偏好会话；每轴区分“沿用默认 / 本次选择 / 本次不使用”且空选择不清空已保存默认；计划可「用这条开始」而不建任务；缺人工说明的原件不可勾选并可就地补写；笛语运维获得最小的缺口分类与回告入口。目录对账诚实结果：风格 20/20、题材 55/55、体裁 41/44，缺 3 条已登记为 CAT-SOURCE-GAP-GENRE-001/002/003，不得宣称 119 项全部登记或全部支持。未证明：有界 DeepSeek 真实内容冒烟未执行（需要正式登录会话，执行侧未创建任何生产登录身份）；真实笛语账号的控制组织仍是推断值、五段画像仍未由有权主体保存；内容质量、真实发布、平台流量与销售未证明。
