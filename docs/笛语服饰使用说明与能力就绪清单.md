## 三种身份与关系

- 笛语系统运维管理员：只负责最小租户开通、停用、恢复和运维审计；`/ops` 不是完整控制平面。
- 笛语服饰租户管理员：维护组织、成员、发布账号、平台目标、ContentRole、五段画像和品牌资料。
- 笛语服饰租户用户：只在本人获准的账号、平台、内容或陈列范围内工作。

身份关系：自然人 → 工作资格 → 逻辑发布账号 → 平台和形式。姓名或工作名只是展示属性，允许
同名；不可变 `user.id` 才是身份键，登录用户名 `lower(username)` 在全系统唯一。

## 发送与生成内容

- 发送：普通交流，不建立 task、run 或 version。
- 生成内容：显式进入正式内容生产，成功后建立 task、run 和不可变 version。

## 管理员从零建立成员

1. 建立或确认成员所属组织。
2. 建立逻辑发布账号，并声明机构账号或个人 IP 的 ContentRole。
3. 为逻辑账号添加所需的平台和形式目标。
4. 确认五段画像 V1；后续修改保存为 V2，历史版本不会被覆盖。
5. 创建成员，填写允许同名的姓名或工作名，以及全系统唯一的登录用户名。
6. 只授予该组织可合法使用的发布账号和画像维护范围。
7. 安全交付一次性 HTTPS 激活或重设链接；最终密码至少 12 位。

正式示例：

- “笛语品控”已经激活并拥有内容账号资格。
- “柯桥店阿丹”已经以正式成员建立；display_name 与历史隐藏身份同名，登录用户名为
  “笛语柯桥店阿丹”，只授予内容账号资格。重复登录用户名会明确返回 `USERNAME_TAKEN`，不会
  产生半成员、半凭据或半授权。

## 常见错误与处理

| 错误码 | 含义与处理 |
|---|---|
| `USERNAME_TAKEN` | 登录用户名已被使用；保留姓名／工作名，改用页面建议的唯一中文用户名。 |

| `FACT_SOURCE_REQUIRED` | 商品或机构承诺缺可信来源；补字段证据，或改为本轮个人观察。 |
| `PROVIDER_STATUS_UNKNOWN` | 最近观察不够新鲜，不等于服务停机；输入会保留，可稍后重试。 |
