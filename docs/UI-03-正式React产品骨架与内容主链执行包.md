## 唯一目标

在不切换生产默认 UI 的前提下，用现有正式 React 应用和正式 API 交付公共首页、三入口隔离壳及
统一创作端内容主链。租户内容用户能够自然生成 V1、自然修改为 V2、完整回读 V1、返回当前版，
并从同一当前版复制或导出。总部、区域、代理商和门店共用一个创作壳，页面身份和能力只消费
服务端可信会话、发布账号、表达身份、组织资格与当前平台。

## 承重合同

1. 公共首页实现 A“种子找到声音”，总时长 6—8 秒，朱砂只承担一次方向转折，最终交接正式
   VI SVG 并静止约 0.8—1 秒；跳过、键盘和减少动效成立。
2. `/login`、`/tenant-admin/login`、`/ops/login` 分别进入自己的产品空间；错误入口显示人话
   恢复页，API 继续使用 JSON 401/403。
3. `/content` 只消费服务端解析的 `current_target`、发布账号、表达身份和组织资格；平台/账号
   载体切换通过显式导航重新解析，不在客户端猜账号。
4. 普通聊天不创建内容任务。创作请求、自然修改、历史版本、复制与导出复用现有正式任务和版本
   API，不创建平行业务。
5. 创作方向由服务端五轴目录提供；题材、风格、形式优先展示，讲法和连续方式渐进披露。五轴
   均可不选，可保留自然语言自定义，可仅在本人明确选择时保存默认。
6. 体型相关方向默认隐藏，只在本人主动启用后出现；实验、未支持、明确不做、来源缺口与内部
   稳定 ID 不进入普通面板。
7. 未明确选择的素材不进入任务；不选素材不阻断无素材依赖的创作。普通生成、修改和平台表现
   不自动改写个人默认、账号画像、品牌基线、目录或知识。
8. 透明品牌转译保留用户原选择，并在成品导读前用一句人话说明收敛方式。

## 已完成的可观察结果

1. 公共首页使用正式 VI SVG 完成 A“种子找到声音”；正常播放约 `7.2s`，可跳过、可重播，
   `prefers-reduced-motion` 直接显示完整 Logo 与首页。
2. `/login`、`/tenant-admin/login`、`/ops/login` 为独立产品入口；创作端、管理端和运维端
   不共用业务导航。错误入口资格显示人话 HTML，API 仍返回 JSON 401/403。
3. `/content` 使用服务端 `current_target` 与可信身份；总部和门店共用同一 React 壳，但账号、
   表达身份、组织和目标作用域不同。平台切换通过显式导航重新解析。
4. 正式 API 下 V1→自然修改 V2→完整回读 V1→返回当前版成立；页面、复制和导出读取同一版本
   投影，AIGC 提醒一致。普通聊天和失败的非稳定方向预检均不创建半任务。
5. 前端从服务端版本化目录读取五轴；21 项默认可见，4 项体型方向仅本人主动启用后可见。
   自定义原话、每轴“本次不使用”、显式保存个人默认、面板选择优先级和透明品牌转译成立；
   未支持、实验、明确不做、来源缺口与内部稳定 ID 不进入普通面板。
6. 仅本次明确选择且可读的合法素材进入请求；不选素材不阻断不依赖素材的任务。开始下一条或
   切换历史任务后，本次选择不泄漏。
7. 租户管理壳与运维壳只表达“品牌管理 / 在这里维护品牌、发布账号与创作资料”和“运行概览 /
   当前运行汇总”，不再从静态页面或统计汇总推断“已可使用、保持就绪、运行正常”；两个产品壳
   仍保持业务 DOM 隔离。
8. 正式 `/content` 未带 `target` 时，服务端以当前正式会话的合法目标集合按固定顺序解析默认值，
   并将同一值用于作用域、目标列表和 `bootstrap.current_target`。小红书、视频号、抖音单一资格
   均可无参数进入；显式未授权目标和零合法目标继续失败关闭，且不创建任务。
