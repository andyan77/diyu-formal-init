# UI-02 全链路高保真 HTML 原型

> 状态：`CLOSED`（2026-07-26，主控按有限范围通过）。关闭只证明静态产品合同、四条连续
> 旅程与高保真离线原型成立；不证明正式 React、正式 API 接入、生产默认 UI 替换或真实用户
> 采用。本目录完整保留为 UI-03 的产品合同证据，不是逐页复制模板。

## 这套原型解决什么

UI-02 把 UI-01R 已确认的产品方向推进为四条可以连续操作的任务旅程，并冻结后续 React
工程化需要遵守的页面与能力合同。它仍是完全离线的静态产品原型，不连接正式 API，不保存
表单，不代表生产界面已经替换。

直接双击 [review/index.html](review/index.html) 即可从连续评审壳浏览全部旅程。裸产品页面位于
`product/`，评审导航、画布控制和内部说明只存在于 `review/`。

## 产品空间与旅程

工程上只有三套隔离空间：

1. **品牌管理**：概览与待处理、成员与权限、发布账号、品牌/商品/组织素材、生产就绪与缺口；
2. **统一创作空间**：总部、区域、代理商和门店共用一套工作壳，以当前发布账号和资格决定可见
   任务；桌面为历史/对话/成品三面，手机只有“对话/成品”两段；
3. **笛语运维**：租户使用状态与有界需求反馈处理。

评审壳中的四条旅程分别为：

- 公开首页 → 独立登录 → 激活与设置密码 → 正确空间 / 人话恢复；
- 品牌管理登录 → 待处理 → 成员资格 → 发布账号 → 共同资料 → 生产就绪；
- 自然输入 → 可选方向与素材 → 内容 V1 → 自然修改 V2 → 完整回读 V1；
- 门店库存与现场输入 → 纯文字陈列参考方案 V1 → 局部调整 V2 → 完整回读文字 V1。

关键状态都可从评审壳直接进入，包括空、加载、一次合并追问、可恢复失败、无历史、无对应资格、
方向展开、素材已选择、V1、V2 和历史回读。产品流程内的表单、抽屉和动作也可以直接点击，
成功结果会在页面中形成稳定落点，不以短暂提示代替。

创作方向折叠区只投影精简 V1：21 项稳定方向默认可以选择，4 项体型相关方向只有本人主动打开
后才出现；实验、未支持和明确不做的能力不进入普通选择面板。逐项消费者与证据边界见
[精简 V1 能力消费者与黄金证据映射](../../能力资产台账/精简V1能力消费者与黄金证据映射_V1.md)。

## 首页 A 动效

首页采用 UI-01R 裁决后的 A“种子找到声音”：一个表达种子短暂试探，在一次朱砂方向转折后，
多余路径退出，整理为正式标志。全程约 `7.4s`，正式 SVG 在约 `6.2s` 完成交接并至少静止呼吸
约 `1s`；点击、触摸、键盘或“跳过”可直接进入首页。减少动效时不播放过程，直接显示正式
Logo 与首页。正式 Logo 始终直接引用 `assets/brand/diyu-vi/svg/`，没有重画。

B/C 继续保留在 UI-01R 历史动效实验室，不进入本轮首页方向。首页主张仍是等待创始人确认的
候选文案，不冻结为永久品牌口号。

## 纯文字陈列边界

陈列搭配只提供完整文字参考方案，用标题、段落、编号和文字表格表达左右、上下杆、正/侧挂、
主次、数量、间距、替代办法与执行顺序。本目录不包含挂杆图、衣服色块、墙面缩略图或效果图，
也不暗示自动还原现场。陈列方案不标 AIGC；页面只给一条自然的“按现场调整”提示。

## 评审说明

- 桌面画布为 `1440×900`，手机画布为 `390×844`；
- “产品流程模式”按旅程浏览，“自由评审模式”列出全部独立状态；
- 顶部可切换画布、上一页/下一页，并在新窗口打开当前裸产品页；
- 评审身份快捷入口包含租户管理员、总部操作者、门店操作者与笛语运维；
- 产品页面中不包含评审页码、开发说明或返回评审目录的控件。

## 明确没有做什么

本目录没有修改正式 React、服务端、API、OpenAPI、数据库、认证、权限、生产配置或生产数据；
没有调用模型、部署或连接平台。UI-03 已在本原型通过有限范围关闭后承接正式 React 骨架与内容
主链；UI-04 才接入纯文字陈列、租户管理、运维等剩余首期业务并进行生产替换。
