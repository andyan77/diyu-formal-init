## 设计审查清单（随本目录评审）

逐条对照，评审时在括号内标 ✅/✋：

1. **一屏一问**：一个首屏只回答一个核心问题（　）
2. **一个主动作**：每阶段最多一个实心主动作（　）
3. **默认智能**：默认模式为"智能"，新用户不需先理解模式选择器（　）
4. **术语字典**：界面只用"创作方案 / 制作包 / 品牌依据"等大白话，
   `CreationProposalV1`、`InteractionResponseV1` 等内部合同名不进普通用户 UI（　）
5. **阶段条轻量**：四步阶段条是状态提示，不做流程向导式压迫（　）
6. **空态有下一步**：空态必有下一动作，不留死胡同（　）
7. **错误保留输入**：错误必保留输入并给恢复动作（　）
8. **作用域内 token**：新组件用 UserShell 作用域内局部设计 token，
   不加剧两套全局 `:root` 互相覆盖（　）

## 已知缺陷（本包发现，未在本包修复）

- `--surface-soft` 在 `product.css` 中被 `.artifact-context-basis` 使用但全仓未定义，
  且无回退值 → 该元素背景实际渲染为透明。修复会改变现有页面观感，
  属设计裁决，随 FE-00 评审一并决定，不在基础设施提交里顺手改。
- `--line-soft`、`--text-muted` 同样全仓未定义，但均带回退值，观感无影响。
