# 笛语产品化 HTML 原型 v0.1

## 目标

这套静态原型用于创始人先确认信息架构、页面层级、用户文案、视觉语言、关键交互、响应式布局和首页品牌动效。它不是正式系统实现，也不连接任何接口或保存数据。

## 页面清单

共 19 张产品页面：公开首页；租户用户、租户管理员、笛语运维三种登录；激活与设置密码；用户首页；内容工作台空状态与成品状态；连续系列与内容计划；私人素材与私人偏好；陈列搭配输入与方案；品牌资料总览；品牌表达；发布账号与成员；商品与组织素材；内容演示；笛语运维首页；统一状态页。`index.html` 只是创始人评审导航，不计入 19 张产品页面。

## 首页动画

定义总时长 7.2 秒，最终浏览器实测约 7.28 秒：呼吸白出现（0.0—0.8 秒）→ 正式弧线路径生成（0.8—2.2 秒）→ 正式朱砂红三角轻落（1.5—2.8 秒）→ 三个正式圆点依次出现（2.4—4.0 秒）→ 符号归位（4.0—5.6 秒）→ 正式横版 Logo 淡入（5.6—6.8 秒）→ 完全定格（6.8—7.2 秒）。动画只播放一次，可跳过和重播；减少动效偏好下直接显示最终 Logo。

参考视频已实际读取，源文件时长约 8.53 秒；没有提交进 Git。原型只吸收了“稀疏元素逐步出现、画面大面积留白、中段短暂停顿、最终标识稳定落位后再出现界面”的节奏与构图关系，没有复制视频里的具体图形、字体、音乐或逐帧内容。

## 从 V1.1 保留的原则

- 一个安静的工作壳，内容生产与陈列搭配清楚分流；
- 自然语言输入为主，成品成为视觉中心；
- 当前版本默认展示，历史版本按需展开；
- 桌面对话与成品并排，移动只保留“对话 / 成品（方案）”两段；
- 创作方向默认收起，每一项都可以不选；
- 发布账号、表达身份、成员与组织不混作同一个对象；
- 正式 VI、克制朱砂红、足够对比度和减少动效支持。

## 本原型取代的现有界面问题

- 登录页从浏览器默认控件改为完整产品界面；
- 首页不再展示入口架构说明，只保留用户唯一可进入的业务入口；
- 用户页面不再讲解系统如何证明自己，首屏直接说明位置、状态和下一步；
- 品牌资料把已完成事项压成摘要，只突出真实缺口；
- 发布账号、成员、平台版本与组织分开操作，低频动作进入抽屉；
- 内容演示退出内部检查清单，只保留账号、系列、当前成品、平台版本和体验入口；
- 当前成品、复制、导出与历史版本使用同一自然语言结构。

## 仍待创始人确认

首页候选文案、Logo 动效的呼吸节奏、首页内容出现时点、页面导航命名、工作台信息密度、管理端列表密度、朱砂红使用强度、移动端固定操作区和内容演示的默认展开层级都仍是候选，不构成正式品牌口号或最终开发基线。

## 打开方式

直接双击本目录的 `index.html`，再从评审导航进入每张页面。全部资源均为仓库内相对路径，不需要启动服务。

## 正式系统边界

本原型没有修改正式 React、服务端页面、接口、认证、权限、数据库、部署配置或生产环境。所有表单和按钮都是本地静态模拟。
