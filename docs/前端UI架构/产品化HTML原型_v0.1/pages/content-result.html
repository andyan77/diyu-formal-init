发布正文

有人进店会先问，有人会先摸一摸面料，也有人只想安静地走一圈。

“我自己看看”不一定是在拒绝谁。很多时候，它只是说：先让我按自己的速度认识这里。

如果我站在门店里，我更愿意先把这句话听完整。需要的时候再出现，不急着替对方决定下一步。

毕竟，逛店不是口试。安静一会儿，也可以是一种认真。
