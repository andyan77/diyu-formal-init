当前版 · V2演示方案

入口右侧挂墙：深灰起笔，米白留白

为什么这样排 入口先由深灰外套建立清楚重点，砖红在中段回应，米白把后半段提亮。顾客能先看懂主次，再决定停在哪一组。

摆放示意

1—3 · 建立重点深灰外套 / 砖红衬衫 / 深灰外套
4—6 · 颜色过渡米白针织 / 砖红衬衫 / 米白针织
7—8 · 收轻米白针织 / 砖红衬衫

这是摆放示意，不是门店实拍。

执行步骤

  1. 先清空单杆，按入口到里侧确认 8 个位置。
  2. 把两件深灰短外套放在第 1、3 位，中间用砖红隔开。
  3. 第 4—6 位完成从米白到砖红再回到米白的过渡。
  4. 最后两位以米白收轻，用一件砖红保持与前段的呼应。

现场检查

  • 站在入口看，第一眼应落在深灰外套，而不是整排平均分散。
  • 两件外套都完整露出肩线，不互相遮挡。
  • 若挂距不足，优先缩小中段间距，不挤压第 1—3 位。
