# 笛语产品化 UI 重构候选基线 v0.1

> 状态：`SUPERSEDED`。本文随 UI-01 完整保留为 19 页覆盖盘点与历史反例，后继为
> UI-01R；不代表创始人已经确认，也不再作为 React 工程化基线。

## 一、新信息架构

### 1. 公开与认证

- 公开首页只承担品牌定格与“进入笛语”一个动作。
- 租户用户、租户管理员、笛语运维分别使用独立登录入口，页面内不互相导流。
- 一次性激活与设置密码使用统一产品界面，不展示技术过程。

### 2. 租户用户

- 用户首页只突出“内容生产”和“陈列搭配”两项主要工作。
- 内容生产包含：开始内容、当前成品、连续系列、内容计划、私人空间。
- 陈列搭配包含：开始方案、当前方案与局部修订。
- 发布账号与当前平台版本放在工作上下文中，避免与个人身份混淆。

### 3. 租户管理员

- 品牌资料首页只回答当前是否可创作、真正缺什么以及下一步。
- 二级页面为：品牌表达、发布账号与成员、商品与组织素材、内容演示。
- 发布账号、成员、门店或部门、平台版本分别操作；低频创建动作进入抽屉。

### 4. 笛语运维

- 运维首页集中显示租户、基础运行状态、未满足需求候选与必要租户操作。
- 信息密度可以高于用户端，但使用业务对象和自然状态，不模拟裸数据工具。

### 5. 公共状态

- 加载、空状态、可恢复失败、无资格访问、删除确认与成功提示使用统一模式。
- 状态页必须同时说明发生了什么和用户下一步可以做什么。

## 二、用户语言映射

| 系统概念 | 用户界面用语 |
| --- | --- |
| 入驻与就绪 | 品牌资料 |
| 演示内容验收 | 内容演示 |
| 账号与操作人 | 发布账号与成员 |
| 本轮商品资料 | 商品资料 |
| 五段画像 | 账号定位 |
| 控制组织 | 负责团队 |
| 操作者 | 成员或使用者 |
| 内部平台内容载体 | 平台版本 |
| 生成一次性安全进入链接 | 生成体验链接 |

内部证明过程、规则编号、数据实现和测试术语不进入普通用户页面。必要边界压缩为一句自然提示。

## 三、页面层级

1. 每个页面首屏先回答当前位置、最重要状态和唯一下一步。
2. 页面最多出现一个实心朱砂色主动作；其他操作使用描边按钮或文字链接。
3. 当前版本直接展示，历史版本折叠为“历史版本（数量）”。
4. 已完成事项压缩为摘要，只有真实缺少事项才突出。
5. 完整成品固定采用同一用户结构：自然概要、标题、正文或台词、制作说明、发布辅助、自然提醒。
6. 创作方向默认折叠且每项都可不选；私人素材和协作偏好独立于品牌资料。
7. 创建、添加、删除等低频动作使用抽屉或弹窗，不在主页面同时铺开多个大表单。
8. 卡片只承载真实对象或一组强相关操作；列表对象优先使用行式呈现。

## 四、首页动效原则

- 目标时长约 7.2 秒，允许落在 6—8 秒之间。
- 顺序为：呼吸白出现、墨黑弧线生成、朱砂三角轻落、三个圆点依次出现、符号归位、正式字标淡入、完整 Logo 定格。
- 动画使用正式 VI 元素，最终由动画图形无缝交接到正式 SVG，最终一帧必须与 VI 真源一致。
- 静默、只播放一次；点击或触摸可跳过，原型保留重播控件。
- 减少动效偏好下直接显示最终 Logo 和首页内容。
- 不使用粒子、神经网络意象、强光、三维金属或通用科技动效。
- 首页文案在创始人确认前只属于原型候选，不作为正式品牌口号。

## 五、响应式规则

- 桌面基准为 `1440×900`，主要内容宽度约 `1180—1280px`。
- 移动基准为 `390×844`，不得出现横向溢出，触控目标不小于 `44px`。
- 桌面内容工作台允许“对话/输入 + 成品/方案”双工作面；移动只保留“对话 / 成品（方案）”两段切换。
- 页面主标题桌面约 `36—40px`、移动约 `28—32px`；正文 `15—16px`。
- 管理端侧栏在移动端转为可横向浏览的分段导航，表格允许在自身区域内横向浏览。
- 低频抽屉在移动端占满可用宽度；弹窗保留安全边距。
- 朱砂红只用于唯一主动作、当前状态和少量识别点，正文保持足够对比度。
