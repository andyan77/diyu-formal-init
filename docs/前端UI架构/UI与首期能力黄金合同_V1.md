## 1. 证据规则

每条黄金合同都必须同时保留：

1. 一个用户能观察到的正向结果；
2. 一个相邻、最容易被误判为通过的反证；
3. 对应正式消费者和对象版本，而非只比较界面文案；
4. 失败可见且不留下半任务、半版本或越权状态；
5. 与风险相称的浏览器、API、数据库或任务留痕证据。

UI-02 不建立自动化。UI-03 自动化内容主链直接承重的
`UI-G01 / UI-G02 / UI-G05 / UI-G06` 与必要 `CAP-G01—CAP-G05`；UI-04 自动化
`UI-G03 / UI-G04 / UI-G07 / OPS-G01 / CAP-G06`，并完成生产切换前的极小 Chromium 冒烟。

## 2. UI 黄金旅程

### UI-G01：首页、动效与入口

- **前置/输入**：匿名访问公开首页；分别覆盖正常动效、点击跳过和
  `prefers-reduced-motion: reduce`。
- **正向结果**：A「种子找到声音」在 6—8 秒内完成；朱砂只承担一次方向转折；最终精确交接
  正式 VI SVG 并静止呼吸至少约 0.8 秒。跳过和减少动效直接进入完整 Logo 与首页。创作空间是
  唯一主动作，品牌管理与笛语运维以低强调链接进入各自独立登录页，三个登录页不互相混列。
- **相邻反证**：不能只让 Logo 零件依次出现；不能因动效遮住入口；不能在公开页混列管理端和
  运维操作或混合登录表单；不能重画或近似复刻 Logo。
- **证据**：真实浏览器计时、减少动效媒体查询、最终 SVG 来源和三种入口导航。
- **自动化去向**：`UI-03`。

### UI-G02：内容 V1 → V2 → V1

- **前置/输入**：有内容资格的操作者在可信发布账号下自然输入；创作方向默认收起，可选合法素材。
- **正向结果**：完整成品 V1 有自然概要、标题、正文/台词、制作说明、发布辅助与 AIGC 提醒；
  一条自然修改形成内容实质变化的 V2，V1 保持可读；复制和导出使用当前所见版本并带相同提醒；
  用户可以进入系列或继续下一篇。
- **相邻反证**：修改不能只换版本号或标签；回读 V1 不能显示 V2；未明确选择的素材不能被任务
  消费，但不选素材不能阻断本来不依赖素材的创作；复制与导出不能重新暴露内部脚手架；普通聊天
  不能误建内容任务。
- **证据**：React 旅程、请求与任务版本关系、冻结快照、复制/导出文本对照及失败原子性。
- **自动化去向**：`UI-03`。

### UI-G03：纯文字 DM01 V1 → V2 → V1

- **前置/输入**：有陈列资格的门店用户自然说明库存、挂杆数量和现场条件。
- **正向结果**：V1 是完整文字参考方案，以标题、段落、编号或文字表格写清左/中/右、上/下杆、
  正挂/侧挂、焦点、数量、间距、替代办法和执行顺序；自然局部反馈形成文字 V2；V1 可回读，当前
  方案可复制。
- **相邻反证**：不出现挂杆图、衣服色块、空间缩略图、墙面预览或“可视化效果图”承诺；不标注
  AIGC；不要求确认人、审批、授权、责任声明或采用回执；局部修改不能破坏库存守恒。
- **证据**：React 旅程、正式 DM01 API/版本对象、V1/V2 文本对照和内部 layout 守恒反证。
- **自动化去向**：`UI-04`。

### UI-G04：租户管理完整旅程

- **前置/输入**：具有租户管理资格的会话从独立管理入口登录。
- **正向结果**：管理员从一至三项真实待处理出发，能够创建/停用成员、签发激活链接、分配入口
  资格，建立发布账号、ContentRole、所属组织和操作者关系，维护品牌表达、商品和组织素材，并
  查看生产就绪与局部资料缺口。
- **相邻反证**：管理员不能编辑全局目录、读取私人素材/偏好、改变他人个人表达设置或进入笛语
  运维；创建成员、创建账号和添加平台版本不能混成一个大表单；已完成项不能伪装成缺口。
- **证据**：角色限定的 React 旅程、服务端资格反证、对象详情/列表变化和一次性链接既有安全合同。
- **自动化去向**：`UI-04`。

### UI-G05：总部与门店同壳、不同资格和作用域

- **前置/输入**：总部/区域/代理商与门店操作者分别通过统一创作入口，以服务端可信组织、当前发布
  账号、ContentRole 和操作者资格启动。
- **正向结果**：共用同一创作壳；顶部明确当前账号、表达身份和目标平台。只有内容资格者不看见
  陈列入口；同时具备内容与陈列资格者可显式选择任务；账号切换必须主动发生。
- **相邻反证**：不能复制四套前端；不能用灰色禁用菜单展示无资格模块；不能按账号名称或客户端
  参数猜资格；双入口自然人不能被静默换身份或混合导航。
- **证据**：两类可信会话的 DOM/导航差异、请求作用域和匿名/错误账号反证。
- **自动化去向**：`UI-03`。

### UI-G06：桌面、移动、键盘、触控和无溢出

- **前置/输入**：桌面 `1440×900`、移动 `390×844`，覆盖空态、加载、合并追问、失败、V1、V2、
  历史版本和长文字成品。
- **正向结果**：桌面保持导航/对话/成品工作面；移动只保留“对话/成品（方案）”两段，身份与平台
  压成一行，复杂选择进入抽屉；键盘顺序可理解、焦点可见、触控目标不小于 44px、没有横向溢出。
- **相邻反证**：不能通过截断正文、隐藏历史或缩小文字来消除溢出；抽屉打开后焦点不能落到背景；
  同一状态最多一个实心主动作。
- **证据**：真实 Chromium 两种视口、键盘遍历、目标框尺寸、`scrollWidth/clientWidth` 与控制台。
- **自动化去向**：`UI-03`，UI-04 增补全业务页极小冒烟。

### UI-G07：三入口隔离、错误恢复与无半状态

- **前置/输入**：匿名访问、错误入口资格、跨入口已有会话、过期激活和一次业务写入失败。
- **正向结果**：租户用户、租户管理员、笛语运维分别进入自己的登录和产品空间；用户页面返回人话
  恢复页和返回/退出重登动作，API 保持 JSON 401/403；失败后没有半成员、半账号、半任务或半版本。
- **相邻反证**：不能返回裸 JSON 给页面；不能静默授予资格或跨入口重定向成另一个身份；不能因
  前端隐藏就把服务端越权当成通过。
- **证据**：页面与 API 双层反证、会话作用域、数据库对象计数或既有原子事务证据。
- **自动化去向**：`UI-04`。

### OPS-G01：运维有界待办处理

- **前置/输入**：有笛语运维资格的会话打开租户、基础服务状态和未满足需求候选。
- **正向结果**：运维可在有界详情中分类、写自然回告并完成当前待办；用户可读结果；正式目录、
  知识、方法、账号画像、私人偏好和系列前情不自动变化。
- **相邻反证**：运维页不能成为裸数据库、全局目录随手编辑器或租户私人资料入口；处理候选不能
  自动学习或激活能力。
- **证据**：受控运维入口、候选前后状态与正式对象不变反证。
- **自动化去向**：`UI-04`。

## 3. 能力黄金合同

### CAP-G01：目录状态与前端可见性

- **正向结果**：前端从服务端目录读取稳定 ID 和版本；普通面板只出现当前精简 V1 的
  `verified/composable` 项，21 项默认可见，4 项体型相关仅主动启用后出现。
- **相邻反证**：`experimental/unsupported/explicitly_out_of_scope`、三个来源缺口以及
  `CAT-*` 标识不能进入普通用户文案；前端不能硬编码条目或提供全局目录编辑面。
- **证据**：目录真源、服务端响应、React DOM 与过期版本失败关闭。
- **自动化去向**：`UI-03`。

### CAP-G02：适用资产选择、版本留痕和无关资产排除

- **正向结果**：只有当前租户、品牌、账号和任务适用的合法素材/资产被明确选择；任务快照记录
  实际版本，重放使用冻结版本。
- **相邻反证**：未选择、跨租户、跨自然人、版本变化或不满足 `use_when/avoid_when` 的资产不得
  进入；`active` 不能被解释为每次生成都调用。
- **证据**：任务快照/运行回执、素材和资产选择结果及相邻越权失败。
- **自动化去向**：`UI-03` 覆盖内容主链；UI-04 扩到其余业务页。

### CAP-G03：风格实质变化，品牌与事实边界不变

- **正向结果**：同一任务选择两种不同稳定风格时，标题、开头、句式、节奏和受众关系出现可感知
  差异；品牌身份、商品事实和核心判断保持一致。发生克制转译时保留用户原选择并自然说明收窄。
- **相邻反证**：不能只替换风格标签或形容词；不能静默覆盖用户选择；不能为增强风格补造顾客、
  经历、商品性能或经营做法。
- **证据**：两份成品及任务快照/应用方向对照，至少一条透明转译。
- **自动化去向**：`UI-03`。

### CAP-G04：题材改变内容主线，体型项只主动启用

- **正向结果**：选择不同题材时，受众问题、展开主线和主要回报随之改变；四项体型相关方向只有
  本人主动启用才显示和可提交。
- **相邻反证**：不能只更换标题标签；系统不能从文本、照片、账号或商品推断体型；不能贬损体型
  或承诺穿着效果。
- **证据**：两种题材的成品与快照对照；体型目录隐藏、主动启用和未启用提交失败三联证据。
- **自动化去向**：`UI-03`。

### CAP-G05：体裁改变媒体组织，而非替换标签

- **正向结果**：图文、口播、试穿/展示或教程讲法选择会改变标题/开头、阅读或观看链、图序/镜头、
  台词/正文和制作说明；平台重编译仍保持源任务核心判断和事实。
- **相邻反证**：不能只替换体裁或平台名称、标签和建议时长；不能把视频台词切成图卡冒充图文，
  也不能承诺系统生成图片或视频。
- **证据**：`GraphicProductionBundle` / `VideoProductionBundle`、源与目标版本关系及成品结构对照。
- **自动化去向**：`UI-03`。

### CAP-G06：新事实、安全、权限、路由或 H 规则的正向与相邻反证

- **正向结果**：任何新增事实源、安全/权限边界、入口路由或 H 类规则，都必须有一个合法正向案例
  和一个仅改变相邻关键条件的失败案例，并留下当前对象与版本证据。
- **相邻反证**：不能只测理想路径、用客户端字段冒充可信作用域、用关键词样句代替结构边界，或
  通过放宽事实/权限让测试变绿；失败不能产生半状态。
- **证据**：与改动同层的最小测试、服务端可信作用域和必要数据库/事件留痕；不要求为 243 条资产
  各建一个测试。
- **自动化去向**：`UI-04`，以后仅在相应新能力真实进入消费者时追加。
