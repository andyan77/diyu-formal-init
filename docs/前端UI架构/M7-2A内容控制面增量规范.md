# M7-2A 内容控制面增量规范

> 性质：对现行 V1.1 交互真源的**增量**，只描述 M7-2A 新增或改动的部分。
> 未在此列出的 V1.1 内容一律保持原样。证据等级沿用 V1.0 修订规范第 0 节：
> 本文件所述为**已实现**（可由 `frontend/src/main.tsx`、`frontend/src/styles.css` 核对），
> 但不代表真实用户已验证。

## 1. 不新建第二套页面结构

复用现有 React 工作壳与正式 VI。**不新增设置页**、不新增第三个移动端标签、不新增独立路由。
新增能力全部落在既有三处：内容生产工作台、租户管理账号卡、租户用户本人入口。

## 2. 创作方向（可选）

位置：内容生产主输入框内部、发送按钮之上，是一个默认收起的 `<details>`。

- 收起时只显示一行自然摘要（未选择时显示「不指定也可以，直接自然说就行」）；
- 展开后只有五行：题材（这次讲什么）、讲法（怎样展开）、风格（希望是什么感觉）、
  形式（怎样呈现）、连续（独立单篇还是连续表达）；
- 每轴一组胶囊按钮，首项恒为「不指定」；**每轴至多选一个**，再点一次即取消；
- 选项来自 `GET /api/v1/content/expression-catalog`，React 不硬编码任何目录条目；
- 面板末尾是「还想补一句就写在这里」自由文本，自然语言自定义始终保留；
- 面板默认**仅本次使用**。「以后优先这样帮我」是独立按钮，调用偏好接口；
  「这次不读取、也不写入我的私人偏好」是独立勾选框；
- P1—P5 与平台路由继续留在后台，不向普通用户显示。

可访问性：每个选项是真实 `<button type="button">`，带 `aria-pressed`；每轴一组
`role="group"` 并带 `aria-label`；选中态同时使用朱砂红与 `✓` 前缀，颜色不是唯一状态表达。

## 3. 这次参考（可选）

位置：创作方向面板末尾的 `<fieldset>`，**不是第六轴**。

- 只列出当前作用域内本人可用的素材，逐条勾选；
- 文字素材直接进入本次上下文；图片、视频只使用用户自己写的原件说明，
  条目上明确标注「已写原件说明 / 还没写原件说明」；
- 未勾选的素材不进入上下文；系统不解析原件画面。

## 4. 透明品牌转译

成品面板中，转译提示位于**成品导读（outline）之前**，使用 `.translation-notice`
左侧朱砂红细边样式，一句人话说明保留了什么、按哪条边界收成了什么、可以继续改。
它不进入正文，不显示审查报告、技术字段或主张谱系。

## 5. 冷启动内容机会与轻量计划

- 原先硬编码的 `ZX-C218` 等 starter prompts 已删除，改为
  `POST /api/v1/content/opportunities` 返回的真实上下文机会；数量由当前可成立的机会决定；
- 点击机会只填入主输入框、方向面板与参考勾选，**不创建任务**；
- 「换一批」只重新读取，不创建任何留痕；
- 侧栏新增「内容计划」：一份可增删改的清单，保存到账号/本人作用域。
  不排期、不提醒、不打分；只有「生成当前成品」才真正开工。

## 6. 账号五段人话画像

- 身份抽屉新增一行「账号画像」，显示当前版本号与表达身份摘要；重复的「实际操作人」行已删除；
- 侧栏新增「账号画像」：一张卡片，五段依次可编辑；
- 无维护资格者字段只读，并明确说明「维护资格由账号控制组织决定」；
- 有维护资格者的主按钮文案是**「保存为当前版本」**，不使用逐任务「授权、审批、签字」语义；
- 租户管理员从既有账号卡内展开「表达画像」原位维护本组织控制的账号；
  非本组织控制的账号只读。

## 7. 私人创作偏好

位置：租户用户本人入口（`/user`）现有「本人默认表达人设」卡片之下，不新建页面。
支持查看、修改、关闭、恢复、删除，以及体型相关方向的主动启用开关。
删除使用二次确认，文案为「删除后找不回来。系列、成品和账号画像都不会受影响。」

## 8. 错误与移动端

- 生成失败只更新提示条：主输入、平台、方向选择、自由文本和素材勾选全部保留
  （组合状态提升到 `ContentWorkbench`，失败路径不清空）；
- 移动端仍只有「对话 / 成品」两段切换；创作方向在对话页内展开；
- 320px / 390px 下方向行、计划行与参考勾选改为单列，长标签使用 `overflow-wrap:anywhere`，
  页面主体不出现横向滚动。

## 9. 视觉

沿用正式 VI：墨黑 `#171614`、朱砂红 `#B7462E`、石灰灰 `#8A887F`、呼吸白 `#F8F7F3`。
朱砂红只用于当前状态、焦点和首要动作；不使用紫蓝渐变、机器人头像、魔法星星或发光边框；
本轮不重制 V1.1 全套高保真状态图。

## 10. 单一有界修复轮增量（2026-07-25）

### 10.1 创作方向：每轴三态

| 状态 | 什么时候出现 | 界面表现 |
|---|---|---|
| 本次明确选择 | 用户点了某个选项 | 该选项 `aria-pressed=true`；收起摘要显示标签本身 |
| 沿用默认 | 用户没动，且这一轴有已保存默认 | 行内提示"这一轴沿用你保存的默认：X"；收起摘要显示"X（沿用你保存的默认）" |
| 本次不使用 | 用户点了"本次不用默认：X" | 行内提示"这一轴本次不使用"；收起摘要显示"风格：本次不使用" |

没有已保存默认的轴才出现"不指定"按钮。**沿用默认绝不显示为"不指定"。**
"以后优先这样帮我"保存的是"当前实际在起作用的方向"，不是空对象；本次关掉的轴才被丢弃，
没动过的已保存默认原样保留。

### 10.2 临时无偏好会话

方向面板底部的勾选项从"这次不读取我的私人偏好"改为**「临时不读取也不写入我的私人偏好」**。
勾选后：前端在**每一次**请求上带 `X-Diyu-Preference-Session: bypass`；目录、可以这样开始、
生成与修改都不读不写私人偏好；"以后优先这样帮我"按钮消失；「我的」入口的偏好读写返回一句
人话说明而不是静默降级。取消勾选立即恢复。

### 10.3 这次参考

缺人工说明的图片/视频**勾选框禁用**，文案为"还没写说明，先补一句才能选"，并就地提供
「先补一句说明」→ 一行输入 + "保存这句说明"。保存后该原件立即可选。系统仍然不读取原件字节。

### 10.4 内容计划

每一条计划新增「用这条开始」：只把标题、备注带回自然输入区，把方向带回面板，并切回撰写面。
点击它不创建任何任务；提示语明确说"现在还没有创建任何任务"。

### 10.5 身份抽屉

「账号画像」行新增「去看这张画像」，直接进入既有账号画像编辑卡。**不新建设置页。**

### 10.6 租户管理：控制组织声明

既有账号卡内的「表达画像」展开区顶部新增一行控制组织说明：

- `declared` → "（已明确声明）"；
- `inferred` → "（迁移时按创建事件推断，不作为依据；需要有权主体明确声明）"；
- 未声明 → "还没有声明"。

未声明或仅为推断时，提供组织下拉 + 「声明控制组织」按钮（一次性）。新建账号表单也增加
「控制这个账号的组织」下拉，默认"暂不声明控制组织（画像先无人可维护）"，并明确说明系统不会
按账号名、身份名或操作者姓名替用户推断。

### 10.7 交互验证

`frontend/test/interaction.test.tsx` 在 jsdom 中真实挂载工作台并逐步点击，覆盖：面板默认收起、
沿用默认摘要、关掉某一轴、缺说明原件不可勾选并补写、真实请求体含 `cleared_axes`、
临时无偏好会话的请求头与不再读取偏好、计划带回不建任务、身份抽屉进入画像卡。
运行入口 `make frontend-test`（CI 同步执行）。**不再只靠源码字符串断言，也不建设测试平台。**

## 11. 主控终审极小返工增量（2026-07-25）

本轮前端只改测试运行入口，界面无变化：

- `frontend/test/run.mjs` 改用 `Object.defineProperty` 安装 jsdom 全局对象。Node 20 没有全局
  `navigator`，Node 22/24 把它定义成**只读取值器**，模块内直接赋值会抛
  `TypeError: Cannot set property navigator`。修复后 Node 20 与 Node 22 均实跑通过；
  CI 仍固定 Node 20，本地任一版本都能跑同一条 `make frontend-test`。

服务端侧与界面相关的两条口径变化（前端文案不需要改，但读代码时应知道）：

- 同一轴的取值优先级为 **本次面板明确选择 > 本次自然语言中未被否定的精确标签/别名 > 已保存
  默认**。因此面板显示「沿用默认」的轴，若这次说话时正好否定了那条默认（如「这次不要干货」），
  本次结果里不会出现它，而**保存的默认值不变**——下一次不说话时仍会沿用；
- 「修改」不再受私人偏好影响：同目标修改只重放快照，跨目标改编也不读今天的偏好。
