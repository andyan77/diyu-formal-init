# M7-2A 内容控制面增量规范

> 性质：对现行 V1.1 交互真源的**增量**，只描述 M7-2A 新增或改动的部分。
> 未在此列出的 V1.1 内容一律保持原样。证据等级沿用 V1.0 修订规范第 0 节：
> 本文件所述为**已实现**（可由 `frontend/src/main.tsx`、`frontend/src/styles.css` 核对），
> 但不代表真实用户已验证。

## 1. 不新建第二套页面结构

复用现有 React 工作壳与正式 VI。**不新增设置页**、不新增第三个移动端标签、不新增独立路由。
新增能力全部落在既有三处：内容生产工作台、租户管理账号卡、租户用户本人入口。

## 2. 创作方向（可选）

位置：内容生产主输入框内部、发送按钮之上，是一个默认收起的 `<details>`。

- 收起时只显示一行自然摘要（未选择时显示「不指定也可以，直接自然说就行」）；
- 展开后只有五行：题材（这次讲什么）、讲法（怎样展开）、风格（希望是什么感觉）、
  形式（怎样呈现）、连续（独立单篇还是连续表达）；
- 每轴一组胶囊按钮，首项恒为「不指定」；**每轴至多选一个**，再点一次即取消；
- 选项来自 `GET /api/v1/content/expression-catalog`，React 不硬编码任何目录条目；
- 面板末尾是「还想补一句就写在这里」自由文本，自然语言自定义始终保留；
- 面板默认**仅本次使用**。「以后优先这样帮我」是独立按钮，调用偏好接口；
  「这次不读取、也不写入我的私人偏好」是独立勾选框；
- P1—P5 与平台路由继续留在后台，不向普通用户显示。

可访问性：每个选项是真实 `<button type="button">`，带 `aria-pressed`；每轴一组
`role="group"` 并带 `aria-label`；选中态同时使用朱砂红与 `✓` 前缀，颜色不是唯一状态表达。

## 3. 这次参考（可选）

位置：创作方向面板末尾的 `<fieldset>`，**不是第六轴**。

- 只列出当前作用域内本人可用的素材，逐条勾选；
- 文字素材直接进入本次上下文；图片、视频只使用用户自己写的原件说明，
  条目上明确标注「已写原件说明 / 还没写原件说明」；
- 未勾选的素材不进入上下文；系统不解析原件画面。

## 4. 透明品牌转译

成品面板中，转译提示位于**成品导读（outline）之前**，使用 `.translation-notice`
左侧朱砂红细边样式，一句人话说明保留了什么、按哪条边界收成了什么、可以继续改。
它不进入正文，不显示审查报告、技术字段或主张谱系。

## 5. 冷启动内容机会与轻量计划

- 原先硬编码的 `ZX-C218` 等 starter prompts 已删除，改为
  `POST /api/v1/content/opportunities` 返回的真实上下文机会；数量由当前可成立的机会决定；
- 点击机会只填入主输入框、方向面板与参考勾选，**不创建任务**；
- 「换一批」只重新读取，不创建任何留痕；
- 侧栏新增「内容计划」：一份可增删改的清单，保存到账号/本人作用域。
  不排期、不提醒、不打分；只有「生成当前成品」才真正开工。

## 6. 账号五段人话画像

- 身份抽屉新增一行「账号画像」，显示当前版本号与表达身份摘要；重复的「实际操作人」行已删除；
- 侧栏新增「账号画像」：一张卡片，五段依次可编辑；
- 无维护资格者字段只读，并明确说明「维护资格由账号控制组织决定」；
- 有维护资格者的主按钮文案是**「保存为当前版本」**，不使用逐任务「授权、审批、签字」语义；
- 租户管理员从既有账号卡内展开「表达画像」原位维护本组织控制的账号；
  非本组织控制的账号只读。

## 7. 私人创作偏好

位置：租户用户本人入口（`/user`）现有「本人默认表达人设」卡片之下，不新建页面。
支持查看、修改、关闭、恢复、删除，以及体型相关方向的主动启用开关。
删除使用二次确认，文案为「删除后找不回来。系列、成品和账号画像都不会受影响。」

## 8. 错误与移动端

- 生成失败只更新提示条：主输入、平台、方向选择、自由文本和素材勾选全部保留
  （组合状态提升到 `ContentWorkbench`，失败路径不清空）；
- 移动端仍只有「对话 / 成品」两段切换；创作方向在对话页内展开；
- 320px / 390px 下方向行、计划行与参考勾选改为单列，长标签使用 `overflow-wrap:anywhere`，
  页面主体不出现横向滚动。

## 9. 视觉

沿用正式 VI：墨黑 `#171614`、朱砂红 `#B7462E`、石灰灰 `#8A887F`、呼吸白 `#F8F7F3`。
朱砂红只用于当前状态、焦点和首要动作；不使用紫蓝渐变、机器人头像、魔法星星或发光边框；
本轮不重制 V1.1 全套高保真状态图。
