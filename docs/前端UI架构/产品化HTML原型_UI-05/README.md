# UI-05 Gate A 高保真交互原型

本目录冻结 UI-05 的产品语义和交互方向，供创始人在正式工程实现前一次性裁决。它是静态演示，不连接正式接口、不保存数据，也不代表生产页面已经更新。

## 本轮冻结的方向

- 登录成员与发布账号分开：成员获得入口资格，并被允许操作一个或多个发布账号。
- 一个发布账号统一承载账号画像、成员与三个平台；小红书图文和视频构成两个内容目标。
- 创作者在同一发布账号下选择平台和形式；输入文字与页面选择冲突时明确询问，不静默改写。
- 账号画像只有一份，五段内容跨平台共享；平台不会另造一套人设。
- 管理概览从真实待办开始；团队使用展示近 7 日与近 30 日聚合，不展示正文或私人资料。
- “当前可用与待补”逐项说明已有依据、缺少资料、影响、直接入口、来源和更新时间，不使用虚假完整度。
- 品牌资料库按业务对象分区，演示来源、字段预览、适用范围、版本、缺项和保存后的影响。
- 生成中只展示可信过程状态，完整内容在最后一次出现；演示页面不流出中间正文。

## 交互清单

- 管理导航与页面跳转；
- 团队使用 7 日 / 30 日切换；
- 添加成员抽屉与体验链接结果；
- 账号画像编辑抽屉与版本提示；
- 品牌资料七类标签与四步导入；
- 平台与形式联动；
- 页面所选平台/形式与自然语言冲突提示；
- 创作方向展开；
- 连续生成状态与最终成品；
- 移动端“对话 / 成品”切换；
- 复制和导出演示。

所有资料均明确为演示信息，不包含密码、令牌、真实私人素材或生产密钥。正式 React、API、数据库、权限、生产配置和资产激活状态均未在 Gate A 修改。
