有时候走进一家店，只是想安静地看一会儿。

不急着回答喜欢什么，也不一定需要马上有人介绍。对我来说，这种沉默不是冷淡，更像是在给自己一点时间：看看颜色，摸摸衣服，也听听自己现在真正想穿什么。
