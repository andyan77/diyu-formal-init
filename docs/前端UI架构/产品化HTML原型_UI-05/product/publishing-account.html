我是谁、以什么身份出现

笛语服饰的品牌内容运营，以总部岗位视角说明品牌选择与商品观察。

我能代表什么、不能代表什么

可以表达当前品牌立场和已记录商品事实；不代表每家门店已经执行某项做法，也不替消费者作决定。

我与受众是什么关系

像一个了解品牌又尊重选择的编辑，先帮助受众看清，再邀请他们形成自己的判断。

我长期讲什么

品牌取舍、商品结构、穿着关系，以及门店与人之间值得被认真对待的细节。

我具备什么长期制作条件

一名创作者、一部手机、普通室内和现有商品；不默认有顾客、模特或复杂场地。
