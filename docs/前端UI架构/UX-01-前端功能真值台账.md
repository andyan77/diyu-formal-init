## 统计与直接裁决

- 真实可用：`50`
- 有缺陷：`6`
- 纯占位：`2`
- 重复或应删除：`3`
- 尚无法证明：`3`
- 合计：`64`

管理员创建用户的 API、入口资格、账号授权和一次性 token 机制真实可用；**管理员拿到的不是
完整 HTTPS 链接**，新建链接不可点击，重设链接还缺复制动作。另一浏览器使用 token 的后端
能力成立，但真实用户不能直接从当前 UI 完成“复制完整链接 → 在另一浏览器打开”的自然流程。

UX-02 的首批阻断消费者是：FT-016/017/021/038/047/048/055；其中 FT-048 当前为尚无法
证明，其余为已复现缺陷。其余 UX-02 项属于信息架构、
视觉层级和一致性工程化，不得把本原型写成已经上线。
