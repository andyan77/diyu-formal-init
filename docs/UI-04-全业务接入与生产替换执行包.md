## 唯一业务目标

在 UI-03 的正式 React 产品骨架和既有正式 API 上补齐首期全部直接消费者，并用唯一候选 CI、
有界备份和生产部署替换当前默认 UI。租户用户可完成内容、系列、素材和纯文字陈列任务；租户
管理员可完成当前租户的成员、账号、品牌、商品、组织素材与就绪维护；笛语运维可完成有依据的
租户操作和未满足需求分类回告；公共入口具备安全、自然的状态与恢复页面。

## 承重边界

1. 复用现有认证、可信会话、RLS、业务对象、API、事务和版本链；前端不提交租户、品牌、组织
   或账号作为可信切换依据。
2. DM01 只交付文字参考方案，覆盖左右、上下杆、正侧挂、商品分组、数量、间距、替代办法、
   步骤和库存守恒；不绘图、不标 AIGC、不要求确认、授权、审批或采用回执。
3. 系列复用既有 `SeriesState` 和任务冻结；素材只有被本人明确选为“本次参考”才进入任务。
   私人素材不跨自然人，组织素材不自动成为知识或品牌事实。
4. 三个产品空间共用基础视觉和 API 客户端但不共用业务导航；页面权限由服务端决定，API 继续
   JSON 401/403，页面提供人话恢复动作。
5. 运行资产保持 41 条（20 知识、21 方法），候选保持 243 条，目录保持 25/119；不激活资产、
   不清偿 39 项缺口、不猜补 3 个来源缺口。
6. 除现有 API 无法满足直接消费者外不新增接口；默认无数据库迁移。任何新增事实、安全、权限
   或路由边界必须有一条合法正向和一条相邻失败反证。
7. 不建设第二套认证、权限、业务对象、状态机、微前端、设计系统网站、审核平台、监控平台、
   多模态、自动发布、交易或 ERP/POS。

## 交付切片

### 租户用户

- 内容 V1→V2→V1、当前版、复制导出和 AIGC 提醒保持同一投影；
- 创建、选择和继续系列，读取既有系列与冻结前情；
- 管理本人素材及人工说明，并显式选择本次参考；
- 有资格时进入纯文字 DM01，完成 V1→局部 V2→V1 和复制。

### 租户管理员

- 从最多三项真实待处理事项进入成员与资格、发布账号与 ContentRole、品牌表达、商品和组织素材；
- 创建/停用成员、签发一次性激活链接、维护当前允许的入口与账号资格；
- 建立发布账号、控制组织、操作者关系和画像版本；
- 读取由当前租户真实资料计算的生产就绪缺口。

### 笛语运维与公共入口

- 查看有来源的租户和最小运行汇总，开通/停用租户；
- 读取未满足需求候选，分类并以自然语言回告，不读取私人数据、不编辑目录、不激活资产；
- `/status` 只显示最小、人话、无敏感信息的服务状态；
- 首页、三登录入口、激活、失效链接、401/403 和业务失败均提供自然恢复动作。

- 租户用户可在正式 React 中完成内容 V1→自然修改 V2→回读 V1、复制/导出、创建/选择/继续
  系列，以及本人素材维护和“本次参考”的显式选择；未选择素材不会进入任务。
- 有陈列资格的用户可完成纯文字 DM01 V1→局部 V2→回读 V1和复制。方案以文字表达左右、
  上下杆、正侧挂、分组、数量、间距、替代办法和执行步骤，库存守恒；没有图形暗示、AIGC
