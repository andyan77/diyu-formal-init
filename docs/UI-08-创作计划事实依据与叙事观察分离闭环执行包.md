## 1. 根因和取代关系

UI-07 的前置 Gate 已结构性解决普通交流误建任务，但门后仍把自由文本计划、事实许可证、
block/scene 结构和 Reviewer 语义分类部分交给模型。真实 G3 同时出现 Writer 补造微事件与
品牌信念、Reviewer 把抽象原则误报为事件，故现有证据不能直接裁决换 Writer。

UI-08 取代的是上述宽泛结构，不取代 Gate，也不把 UI-07 改写为成功。结构和真实模型预检
全部通过前，不 push、CI、部署或修改生产。

## 2. CreativePlanV2

停用自由文本 `system_creative_plan: str`。新计划只含：

- `plan_version`
- `topic_spans`：用户输入精确子串
- `primary_value`：既有 P1—P5
- `tone_ids`：显式选择或合法账号基线
- `mechanism_id`：既有稳定 ID，可空
- `platform_shape`：服务端目标平台／形式
- `prohibited_bindings`：固定为 `no_situated_event`、
  `no_institutional_assertion`、`no_user_history_expansion`、
  `no_unregistered_resource`

对象拒绝额外字段，不容纳人物、事件、对白、动机、因果、品牌观点、经营历史、用户履历、
标题、主张或故事梗概。topic 不是用户精确子串、ID 不在服务端允许集合、平台形态漂移或固定
禁用项不完整时，在 Writer 前失败。

## 3. 精确事实与表达约束

`NarrativeBlock` 使用：

- `fact_refs`：可空；每个 ID 必须解析到一条冻结精确文本，只支持用户逐字事实、精确商品
  事实和经确认的精确品牌事实；
- `constraint_refs`：品牌语气、ContentRole、创作方法、平台表达和显式机制，只决定怎么说。

`source:brand_baseline`、`source:role_boundary`、`source:organization` 只能是 constraint，
不能作为 fact。一般观察默认 fact 可空。`institutional_assertion` 只有逐字等于所绑定的
精确品牌事实时才允许，不靠机构词黑名单。

## 4. 服务端最小骨架

服务端在 Writer 前冻结 block ID/type/slot、scene ID、双向关联、允许事实、表达约束、允许
资源与 spoken 顺序。Writer 只填写每个既定 block 的可见文本及每个既定 scene 的动作、声音、
制作提示，并从允许资源中选择；返回额外、缺失、重复或漂移 ID 均失败。

旧任务不批量回填、不改历史快照；缺少新计划或 Frame 的旧任务通过保守 legacy 编译继续
V1/V2、复制、导出、系列和平台父子版本。不新增表或迁移。

## 5. Reviewer 观察类型

Reviewer 的最终类型为：

- `abstract_principle`：抽象原则、观点、价值判断或一般理解；
- `situated_event`：具体或隐含人物在情境中的动作、对白、反应、原因或结果；
- `institutional_assertion`：品牌／组织／门店／账号的信念、承诺、做法或历史主张；
- `user_actuality`、`hypothesis`、`dramatization`、`confirmed_fact`、`uncertain`。

服务端验证完整目标跨度、全 ID 覆盖、事实和资源闭世界。general_observation 中
`situated_event` 无条件失败，不再依赖“人物／关系＋事件”组合；无精确品牌事实的
`institutional_assertion` 无条件失败；`abstract_principle` 可以无 fact 通过。

## 6. 最小反证

在既有 pytest 中证明：

1. “饭桌上一句话让两个人都沉默。”为 `situated_event`，在一般观察中失败；
2. “笛语相信婆媳关系需要换位思考。”为 `institutional_assertion`，无精确品牌事实失败；
3. “换位思考不等于没有边界。”为 `abstract_principle`，不误报事件；
4. intake 计划夹带未出现在用户原话中的事件或品牌立场，在 Writer 前失败且 Writer 0 次。

同时保留 Gate 恶意 ready、用户事实非资源、Reviewer 漏目标／假跨度、D1 演绎提示和 G7
Frame／真人事实／来源不变量。不建新测试平台。
