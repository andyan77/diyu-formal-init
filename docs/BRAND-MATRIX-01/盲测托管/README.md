# BRAND-MATRIX-01 · 密封盲测托管规则

## 一、职责与隔离

- 密封集固定为 20 张卡和一份固定评分表，由**未参与实现的监理**制作并加密托管。
- 执行侧不得生成、改写、补题或查看任何盲测题目。
- 题目与评分表明文禁止进入仓库、工作树和执行窗口；仓库只登记下方无明文字段。
- 解密口令仅由主控持有，不进入仓库、工作树、执行窗口或普通交接材料。

## 二、开封条件

只有以下对象全部冻结后，主控才可开封：

1. 候选 Git SHA；
2. Prompt；
3. 模型；
4. 规则；
5. 数据 manifest；
6. 运行镜像。

开封后不得依据具体题目措辞修改 Prompt、规则、fixture、oracle 或数据。若本轮失败，已开封的
20 卡立即降级为公开回归集；下一轮必须使用全新的密封集。现有公开 15 卡只作普通回归，
不计入本轮 20 卡密封盲测。
