# A-1 · 消费通道分类表

## 口径

每份文档恰有一个 `primary_channel`，混合文档再拆为原子消费项。下表的“消费方”只描述 Gate
B/C/D 的计划消费者，不表示 Gate A 已接线。完整原子表位于
`import-contract.json` 的 `consumption_items`：30 项，全部具备补充件规定的 14 个字段，且
`raw_markdown=false`。其中 7 项可在后续经过选择器形成 Writer 原子上下文，整篇原文为 0；
`internal_template_not_publishable` 进入 Writer 为 0。

## 混合文档隔离

- 商品主档拆成 V 正式准入、P/C 候选、R 禁止三项；价格、效果、性能、精确工艺和精确适配不
  因进入深度 SKU 包而升级。
- 内容治理拆成表达约束与权利/隐私/组织解析两项；后者永不进入 Writer。
- 商品推断规则拆成 V、P/C、R 三个守卫项；R 项没有任何 P1—P5 消费方。
- 账号权限、组织授权、媒体权利与商品判断各由不同确定性组件消费，不因同处一个文档而混入
  同一 Writer 上下文。
