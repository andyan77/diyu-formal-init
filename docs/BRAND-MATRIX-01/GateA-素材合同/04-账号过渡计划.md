# A-4 · 账号过渡计划（不执行）

## 盘点起点

S0 已接受的租户可见账号计数为 9；Gate A 不连库，因此不臆造这 9 个对象的数据库 ID。
manifest 预留 `EXISTING-SLOT-01..09` 九个盘点槽。Gate D 仅在隔离库逐 ID 回读引用、授权、任务、
版本和审计边后，才把槽位绑定到真实对象。

## 现存 9 个对象的路线

| 条件 | 动作 | 默认展示 | 历史 |
|---|---|---|---|
| 存在任何任务、版本、成品、授权或审计引用 | 停用并归档 | 默认隐藏 | 原账号 ID 保留，旧任务按原 ID 回读 |
| 可证明 synthetic 且零引用、零保留授权、零审计依赖 | 精确 ID allowlist 删除 | 不适用 | 删除前后逐对象和引用计数断言，失败回滚 |
| 无法证明属于上述任一类 | 失败关闭，保持原状 | 默认隐藏候选，不执行删除 | 等待人工核对 |

租户管理员与自然人登录身份不因矩阵重建删除。不得改旧任务、旧版本、旧 digest 或历史归属。

## 授权迁移

Gate D 按“自然操作人 → 最小资格 → 新逻辑账号 → 组织作用域”逐条映射。禁止把旧账号的资格整包
复制给新账号，禁止把区域资格放大为总部或跨区域资格。每条迁移须记录旧授权 ID、新授权 ID、
操作人 ID、账号 ID、组织范围、批准依据和回滚动作。

## synthetic 精确删除判据

必须同时满足：存在 synthetic 标记或创建批次来源；任务/版本/成品/引用边均为 0；无保留授权或
审计依赖；目标为精确对象 ID allowlist；提交前后计数和外键断言；事务提交前可回退。任一条件
不成立即改走归档隐藏，不物理删除。
