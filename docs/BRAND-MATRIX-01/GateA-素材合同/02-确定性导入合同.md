## 无静默截断合同

`selection_policy_version=gatea-selection-policy-v1`。运行时排序只能按明确数值优先级再按
`item_id`，禁止按标题字典序。每个 P1—P5 选择结果必须同时持久化：适用产品、账号、组织，
`max_items=24`、`max_characters=12000`、`selected_item_ids`、`excluded_item_ids` 与
`overflow_reason`。超预算时必须逐项登记排除理由，禁止只留选中项或静默丢弃。

Gate A 的两个 ID 数组为空，原因是本 Gate 只冻结合同、没有真实运行；Gate B/C 才填实际结果。
