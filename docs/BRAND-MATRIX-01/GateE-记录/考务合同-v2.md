# BRAND-MATRIX-01 · Gate E 考务合同 v2

状态：`FROZEN_WITH_RUNTIME_CANDIDATE` 前的考务真源。

本合同把卡面元数据解释为操作员必须执行的绑定指令，不要求系统从自然语言猜测商品、媒体或系列：

- P2：必须绑定且只绑定一件正式商品。
- P5：必须绑定两件不同正式商品，并为每件绑定一份十项门 `PASS` 且 P5 资格为真的母版。
- 系列卡：必须绑定 `DIYU-SERIES-001` 或 `DIYU-SERIES-002`；显示名、栏目名或账号名不能冒充系列 ID。
- 卡面用户输入和操作员绑定是两个字段；执行工具必须保持用户输入逐字不变。
- oracle 只执行下方逐项登记且带 `contract_ref` 的义务。没有冻结契约依据的判断不得加入判卷。
- `first_draft_usable` 仅创建人工评分空表，不由机器自评，也不替代前三道硬门。

三卡绑定依据：依 `ADJ-BLIND-ORACLE-03`，B11 第二件商品取 P5 合格池中 CSPU 编号最小者，母版取该商品编号最小合格项。因此执行侧拟定
