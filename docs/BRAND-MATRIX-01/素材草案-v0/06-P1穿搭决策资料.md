# 06 · P1 穿搭决策资料（四款）

> **引用规则（本文件最重要的约束）**
> - **只有 `V` 级字段可以作为确定表述**（视频画面可直接确认：品类、可见颜色、可见轮廓等）。
> - **`P` 级字段（面料倾向、季节、年龄段、尺码段、价格带、优势与取舍）必须标注"待验收"并保持弹性表述**；
>   `DIYU-ASSET-PRODUCT-INFERENCE-001` §15.2 给的推荐写法是"这类面料外观通常会更挺一些，实际成分仍以商品说明为准"。
> - **`C` 级（候选名称、商品角色、风格标签）不得称为企业正式名称**。
> - **`R` 级一律不出现**：精确成分、精确工艺、货号、吊牌价、库存、销量、检测认证、精确尺码适配结果。
>
> P1 专项规则（`DIYU-CONTENT-GOVERNANCE-001` §11.1）：必须有真实问题、判断条件、适用场景、必要时有反选，
> 不制造身材或育儿焦虑；**不得**"用一个答案覆盖所有人"，**不得**"根据视觉推断精确功能和尺码结果"。
>
> 每组末尾的"证据不足时的自然提示"是必答项，不是可选项。

## 1 `DIYU-CSPU-001` 男童亮黄城市工装宽松短袖

| 项 | 内容 |
|---|---|
| **用户场景条件** | 夏季，孩子日常出行、公园与商场轻活动；家长想给孩子添一件"能自己撑住一套造型"的上衣，而不是再买一件白 T。 |
| **引用的主档字段** | **V 级（可直接说）**：品类"男童短袖上衣"、主色"明亮黄色"。**V/P 级**：轮廓"宽松、落肩倾向"。**P 级·待验收**：面料倾向"棉质针织或棉混针织"、季节"春末、夏季、初秋"、年龄段"约6—12岁"、建议尺码"120—170cm"、建议价格带"199—299元"、主要取舍"视觉存在感较强，搭配颜色过多时容易显得杂乱"。**C 级**：商品角色"视觉主推款、搭配中心款"、风格"城市街头、工装休闲"。 |
| **一条可执行选择** | 先决定**这一身里谁当主角**。如果这件当主角，下装和鞋帽就按主档给的方向压住——"中性色工装裤、牛仔裤、帽饰、运动鞋"（P 级建议）；如果孩子那天想穿他自己喜欢的图案裤，就别选这件，换 `DIYU-CSPU-002` 的中灰或 `DIYU-CSPU-003` 的藏蓝来承接。 |
| **一条真实取舍** | 选它换来的是"一件就完成一套"，代价是**它会一直是画面里最响的那个**——主档写明"视觉存在感较强，搭配颜色过多时容易显得杂乱"，也就是说它降低了搭配自由度。 |
| **成立条件** | ①这一身里没有第二个强色；②孩子本人不排斥被看见（主档写明不适合"偏好低存在感、正式学院感或贴身版型的人群"）；③用途是日常与轻活动，不是需要低调的正式场合。 |
| **出门前可观察的检查** | ①让孩子把手举过头顶再放下，看下摆是否明显上移并停在上面——这是**你自己能看见的活动空间**，不是我们给的功能承诺；②看肩线落点是否在孩子肩头以外一段（落肩倾向的正常表现）；③在自然光下看一眼黄色和裤子的关系，画面里是不是只有一个重点。 |
| **证据不足时的自然提示** | 「颜色和轮廓是画面里能直接看到的；面料我们目前只能说**视觉上更接近棉质或棉混针织**，精确成分要以正式商品资料为准。价格是按品类和定位给的**建议区间**，不是实际吊牌价。孩子穿上凉不凉快、跑起来舒不舒服，跟当天的温度和他自己的习惯关系更大，我们不替你下结论。」 |

## 2 `DIYU-CSPU-006` 女童自然度假白色连衣裙

| 项 | 内容 |
|---|---|
| **用户场景条件** | 春末到夏季，家庭短途出行、拍照、自然场景活动；家长想要一件"看起来轻松、拍出来干净"的裙子，同时担心不耐脏。 |
| **引用的主档字段** | **V 级**：品类"女童连衣裙"、主色"白色或米白色"。**V/P 级**：轮廓"宽松、自然展开，A字倾向"。**P 级·待验收**：面料倾向"棉质梭织、棉麻感或轻薄混纺"、季节"春末、夏季"、风格"自然、轻度假、柔和浪漫"、建议尺码"100—160cm"、建议价格带"399—599元"、核心优势"色彩干净，能与草帽、自然场景和轻配饰建立完整氛围"、主要取舍"浅色清洁维护要求较高，宽松轮廓不强调利落腰线"。**C 级**：商品角色"女童视觉形象款"。 |
| **一条可执行选择** | 先回答一个问题：这件是**去外面待一整天**，还是**去一个能坐下来的地方**。前者建议直接跳过它，看深色耐脏的选项；后者再往下比。P2 命题已经把话说死了——"白色连衣裙解决的是轻松和干净，不解决高频耐脏"。 |
| **一条真实取舍** | 选它换来的是氛围完成度（主档写它"能与草帽、自然场景和轻配饰建立完整氛围"），代价是**维护成本和腰线表达**：浅色清洁要求高，宽松轮廓也不强调利落腰线。 |
| **成立条件** | ①活动强度和脏污概率可控；②家里能接受浅色的打理频率；③不需要靠这件建立"利落"的印象。主档写明不适合"高频高强度户外、偏好深色耐脏或强街头风的人群"。 |
| **出门前可观察的检查** | ①让孩子原地转一圈，看裙摆展开时是否会绊到腿；②看肩带或肩缝在抬手后是否回位；③浅色单品出门前先在自然光下看一眼有没有存放期间的印子——这是**目视检查**，不是我们对面料的洁净承诺。 |
| **证据不足时的自然提示** | 「白色和 A 字轮廓是画面里看得见的。面料我们现在只能说**外观更接近棉质梭织或棉麻感**，具体成分和洗护要看正式商品资料。它耐不耐脏、好不好洗，我们没有做过相应测试，也不打算凭感觉说。」 |

## 3 `DIYU-CSPU-008` 女童灰色松弛针织开衫

| 项 | 内容 |
|---|---|
| **用户场景条件** | 换季，早晚温差大，孩子一天里要在教室、户外、车里反复进出；家长想要一件"随时加一件、随时脱下来"的中间层。 |
| **引用的主档字段** | **V 级**：品类"针织开衫"、主色"灰色"。**V/P 级**：轮廓"宽松、落肩、松弛"。**P 级·待验收**：面料倾向"棉混、腈纶混纺或毛感针织"**（本字段正处于 `07` 的 v1→v2 验收升级流程中，未经 founder 确认前维持 v1 表述）**、季节"春秋、初冬室内外"、风格"城市休闲、松弛层次"、建议尺码"120—170cm"、建议价格带"359—559元"、核心优势"中性色和宽松结构搭配范围广，适合层次穿着"、主要取舍"宽松针织可能弱化身体线条，维护不当可能影响形态"。**C 级**：商品角色"核心叠穿款"。 |
| **一条可执行选择** | 把它当**中间层**选，而不是当外套选：先看孩子最常穿的那件上衣，再判断这件能不能松松地套在外面还留出活动量。如果你要的是"出门这一件就够"，它不是答案——主档写明它不适合"追求挺括、正式或高强度户外使用的人群"。 |
| **一条真实取舍** | 选它换来的是搭配范围（中性灰 + 宽松结构，几乎什么内搭都能承接），代价是**形态需要照顾**：主档写明"维护不当可能影响形态"，专业取舍文件也写着"维护和形态稳定性待确认"。这是我们目前还没有确认的一处，不藏着。 |
| **成立条件** | ①用途是室内外切换，不是高强度户外；②家里接受针织类的挂放和清洗方式；③需要的是层次而不是轮廓支撑。 |
| **出门前可观察的检查** | ①拎起肩部轻轻抖一下，看衣身是否自然回到原位；②看袖口和下摆有没有因为存放而变形；③套在孩子常穿的那件上衣外面，看袖窿处是否有明显拉扯。 |
| **证据不足时的自然提示** | 「灰色和松弛轮廓是画面里能确认的。面料我们现在只能给**大类倾向**，而且这一款的形态稳定性**我们自己标了"待确认"**——在正式商品资料进来之前，我们不会说它不会变形，也不会说它一定好打理。」 |

## 4 `DIYU-CSPU-013` 儿童灰色自然机能保暖外套

| 项 | 内容 |
|---|---|
| **用户场景条件** | 深秋到冬季，家庭在海岸、自然或城市近郊的户外活动；画面里常常不止一个孩子，家长希望这一件"站在人群里不打架"。 |
| **引用的主档字段** | **V 级**：主色"灰色"。**V/P 级**：品类"户外保暖外套"、轮廓"宽松、机能层次型"。**P 级·待验收**：面料倾向"防风感梭织与填充结构"、季节"深秋、冬季"、风格"自然机能、海岸户外"、建议尺码"120—170cm"、建议价格带"799—1299元"、核心优势"灰色稳定，适合自然背景和多人关系造型"、主要取舍"机能感较强，对室内、正式和柔美场景适配有限"。**C 级**：商品角色"冬季形象款、场景款"。 |
| **一条可执行选择** | 如果这件是**给多人合影里的那个孩子**买的，它是很合适的选择——主档写明"灰色稳定，适合自然背景和多人关系造型"；如果它要同时承担学校活动、正式场合和日常通勤，那就得先问自己能不能接受它在室内偏"硬"。 |
| **一条真实取舍** | 选它换来的是场景稳定性（户外、自然背景、多人画面都不抢戏），代价是**场景适配面收窄**：主档写明"机能感较强，对室内、正式和柔美场景适配有限"。 |
| **成立条件** | ①主要用途在户外与自然场景；②家庭能接受它在室内偏机能的观感；③不需要它兼任正式或学院感的外套。 |
| **出门前可观察的检查** | ①让孩子把两只手举过头顶再放下，看下摆是否明显上移——**这是活动空间的目视观察，不是防风或保暖结论**；②看帽子（若有）翻起放下后是否遮挡视线；③在自然光下看灰色与内搭的关系，主档给的搭配方向是"黑色、红色或中性色内搭和裤装"。 |
| **证据不足时的自然提示** | 「灰色和机能层次型的轮廓是画面里能看到的。**这件我们特别要说清楚：不谈防风等级、不谈保暖到几度、不谈防水**——面料我们目前只能说外观呈现"防风感梭织与填充结构"的特征，实际成分和任何功能指标都要等正式商品资料。你们那边的冬天它够不够，得你按孩子在外面待多久来判断。」 |

## 5 四款共用的 P1 合格自检

发布前逐条过一遍（`DIYU-CONTENT-GOVERNANCE-001` §11.1 + `DIYU-PRODUCT-TRADEOFF-P2-001` §四）：

| 检查项 | 合格标准 | 本文件状态 |
|---|---|---|
| 有真实问题 | 场景条件是具体的，不是"想买件好看的" | 四组均有 |
| 有判断条件 | 给的是条件不是结论 | 四组的"成立条件"均为条件式 |
| 有反选 | 明确写出什么情况下别选 | 四组均引用主档"不适合"或取舍 |
| 不制造焦虑 | 无身材、年龄、育儿焦虑话术 | 已核，无 |
| 不用一个答案覆盖所有人 | 每组都留了"另一种情况" | 四组均有 |
| 不根据视觉推断精确功能和尺码结果 | 无任何精确尺码适配结论、无功能等级 | 已核，无 |
| P 级保持弹性 | 面料/价格表述均带"倾向""建议""以正式资料为准" | 已核 |
| 无 R 级内容 | 无精确成分、工艺、货号、吊牌价、库存、销量、检测认证 | 已核 |
