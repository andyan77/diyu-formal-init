# 04 · 人物现实原句库（S02 / S04）

> **最重要的一句话**：本文件里的 10 条**全部是 `演示虚构·待founder定稿` 的角色情境素材，
> 不是任何真实员工的经历。** `DIYU-CONTENT-GOVERNANCE-001` §1.4 明确，真实人物的成长经历、
> 工作事件、家庭关系等"不得仅因为内容需要而虚构"；§4.4 给出的反例是
> "创始人在陪女儿逛街时突然明白了这个道理"——**除非该事件由本人确认**。
>
> 因此本库的正确用法是：**把它当成"这个岗位在这类情境里通常会遇到什么"的组织性素材**，
> 而不是"某人某天真的这样了"。每条都强制拆成两栏：**现实事实**（可以说的那部分）与
> **创作指令**（写作时可以自由组织、但不得事实化的那部分）。
>
> 未绑定真人前，两个账号均按组织性岗位人设发声；绑定真人后须另补姓名、真实履历、
> 本人确认的经历、肖像与声音授权、公开与禁止话题（`DIYU-ORG-IP-ACCOUNT-MATRIX-001` §八）。

---

## 0 字段口径

| 字段 | 含义 |
|---|---|
| **原句** | 可直接使用的一句话表达（口播或正文都可） |
| **现实事实 / 创作指令** | 前者是本条允许被理解为"确实如此"的部分；后者是允许创作、但**不得**被写成已发生事实的部分 |
| **允许账号** | 只有列出的账号可用；其他账号引用即构成跨组织冒充 |
| **单次 / 可重复** | 单次＝只能用于一条内容；可重复＝可作为长期角色母题反复使用 |
| **第一人称许可** | 是否允许用"我"来说。全部限定为**角色口吻的"我"**，不指认任何具体真人 |
| **禁推断项** | 从这句话里**不得**引申出来的东西 |

**六项元数据（本文件全部条目统一）**：
来源＝`本包演示虚构，真源无人物素材（DIYU-ASSET-VISUAL-ANALYSIS-001 §三 内容形态表把「创始人或岗位人物内容」一行记为 0 条）`；
确认人＝`AI代行草拟(Opus5)·待founder定稿`；适用组织＝各条自列；版本＝`v1`；
生效／失效＝`2026-08-07 生效 / 绑定真人或 founder 定稿后整体复核`。

## 1 S02 · 杭州搭配顾问（`DIYU-STORE-001`）

### `PS-S02-01`

- **原句**：「两个码之间拿不准的时候，我一般不看年龄，先看孩子最近半年长得快不快。」
- **现实事实**：门店确实存在"两个码之间怎么选"这一高频问题（`SK-HZ-03`）；
  以及"不能只按年龄选"这一专业立场（`DIYU-BRAND-VOICE-001` §8.1 推荐回复方式即写明
  "建议再看身高、肩宽和活动习惯，不能只按年龄选"）。
- **创作指令**：可以铺"半年"这个观察窗口、可以写成对话场景；**不得**写成"上周有位妈妈……"这类具体到店事件。
- **允许账号**：`S02`（主）；`S01` 可在本店语境下引用同一立场，但须换表述。
- **单次 / 可重复**：可重复（属长期角色母题）。
- **第一人称许可**：允许，角色口吻的"我"。
- **禁推断项**：不得推出从业年限、专业资格、接待过多少顾客；不得推出精确尺码适配结果。

### `PS-S02-02`

- **原句**：「我最怕的不是家长挑不定，是三件都试完了，孩子已经不想再穿脱第四次。」
- **现实事实**：本店试衣间两间、周末排队、店内会先平铺比对缩到两件以内再试（`SK-HZ-04`）。
- **创作指令**：可以写"第四次"这种具体计数作为修辞；**不得**写成某次真实排队事故或某个孩子的具体反应。
- **允许账号**：`S02`。
- **单次 / 可重复**：可重复。
- **第一人称许可**：允许。
- **禁推断项**：不得推出门店客流数字、排队时长、成交率；不得把儿童的情绪写成负面评价。

### `PS-S02-03`

- **原句**：「亮色那件挂在最前面，是因为它最容易被看见，不是因为它最该被买走。」
- **现实事实**：`DIYU-CSPU-001` 商品角色为"视觉主推款、搭配中心款"（C 级），主要取舍为
  "视觉存在感较强，搭配颜色过多时容易显得杂乱"；`DIYU-DISPLAY-EXPRESSION-001` §2.2
  要求先形成一个主焦点再组织周边关系。
- **创作指令**：可以写陈列位置带来的心理错觉；**不得**描述杭州店的具体挂杆位置——本店挂杆档案为空（`SK-HZ-05`）。
- **允许账号**：`S02`（主）；`H01` 若引用须改为品牌层表述并去掉门店场景。
- **单次 / 可重复**：可重复。
- **第一人称许可**：允许。
- **禁推断项**：不得推出销量、主推款销售占比；不得暗示其他商品品质更低。

### `PS-S02-04`

- **原句**：「我会先问一句：这件是打算穿一个夏天，还是打算拍两次照。两种答案，我给的建议完全不一样。」
- **现实事实**：品牌基线要求"解释商品为什么成立，也解释它牺牲了什么"，并允许内容明确说明"这件商品不适合谁"；
  AudienceProfile 记核心受众判断包含"是否经得起多次穿着"。
- **创作指令**：可以把两种答案展开成两条建议路径；**不得**编造某位顾客的实际回答。
- **允许账号**：`S02`。
- **单次 / 可重复**：可重复。
- **第一人称许可**：允许。
- **禁推断项**：不得推出顾客消费能力、家庭收入或购买频次。

### `PS-S02-05`

- **原句**：「有一次我说错了，把一件针织讲成了不容易变形，第二天我在群里更正了。」
- **现实事实**：**只有"更正机制存在"这一条是可以表达的立场**——`DIYU-BRAND-VOICE-001` §8.1 面对质疑的
  推荐回复是"这个结论如果没有实际资料支持，我们不会把它写成商品事实"；且"绝对不变形"属原则性禁用词。
- **创作指令**：**本条是全库风险最高的一条**。可以用它讲"讲错了要改"这件事本身；
  **不得**写成某位真实店员在某天真的犯过这个错。
- **允许账号**：`S02`，且**只在明确标注为一般情境时**使用。
- **单次 / 可重复**：**单次**（一次内容用完即止，避免被当成真实事件反复引用）。
- **第一人称许可**：**不允许**用第一人称叙述为已发生事件；只能改写为"如果我们说错了，会这样更正"的条件式。
- **禁推断项**：不得推出真实纠错记录、投诉记录、内部处罚；不得把它写成品牌已建立的正式纠错流程。

## 2 S04 · 成都成长店员 **阿野**（`DIYU-STORE-003` 成都金牛门店）

> **人物定名（founder 2026-08-08 定稿）**：本角色对外账号名为「阿野在笛语·成都金牛店」，
> 叙述主体定名为 **阿野**。
> **「阿野」是 `演示虚构人名·待founder定稿`（按 D-02 演示角色口径登记），不指向任何真实员工。**
> 与 S02 的差别：S02 是**栏目型**账号，不设人名；S04 是**人物成长号**，有叙述主体但**未绑定真人**。
> 未绑定真人前，阿野的一切片段都只是角色情境素材；一旦将来绑定真人，须先补齐姓名、真实履历、
> 本人确认的经历、肖像与声音授权、可讲与禁止话题（`DIYU-ORG-IP-ACCOUNT-MATRIX-001` §八）。

### `PS-S04-01`

- **原句**：「刚来的时候，阿野以为顾客问的是'哪件好看'，后来发现大部分人问的是'我要不要现在买'。」
- **口播改写（第一人称版）**：「刚来的时候我以为顾客问的是'哪件好看'，后来发现大部分人问的是'我要不要现在买'。」
- **现实事实**：AudienceProfile 记核心受众"不只缺商品，更缺清晰、诚实、能够帮助取舍的判断"；
  P1 的产品定位就是"真实穿衣问题与购买决策"。
- **创作指令**：可以铺"刚来的时候"这个成长视角；**不得**写成具体入职日期、培训经历或真实业绩变化。
- **允许账号**：`S04`。
- **单次 / 可重复**：可重复。
- **第一人称许可**：允许，角色口吻。
- **禁推断项**：不得推出真实入职时间、学历、培训记录、销售业绩（`DIYU-CONTENT-ROLE-001` §十二 明令禁止）。

### `PS-S04-02`

- **原句**：「成都的冬天，屋里不冷，门一开才冷。所以阿野现在先问的是'一天里有多少时间在外面'。」
- **口播改写（第一人称版）**：「成都的冬天，屋里不冷，门一开才冷。所以我现在先问的是'一天里有多少时间在外面'。」
- **现实事实**：`RK-SW-01`（四川盆地冬季湿冷、室内多无集中供暖）与 `SK-CD-03`（本店高频问题
  "室内不冷、出门冷，怎么给孩子分层"）。
- **创作指令**：可以写成一句问诊式开场；**不得**给出具体温度数字，也不得由此推出任何保暖等级结论。
- **允许账号**：`S04`（主）；`R02` 可在区域层引用气候部分，但须去掉门店场景。
- **单次 / 可重复**：可重复（本条是 S04 的核心母题）。
- **第一人称许可**：允许。
- **禁推断项**：不得推出精确保暖温度、防风等级；不得引用华东区域的气候知识作对比。

### `PS-S04-03`

- **原句**：「阿野第一次自己接待一整组家庭，最后什么都没成交。」
- **现实事实**：品牌关系姿态含「克制」（不夸大、不煽动、不制造焦虑）与「平等」（不居高临下，不替消费者定义人生）；
  声纹禁用"闭眼入""不买后悔"等逼单表达。
- **创作指令**：可以保留"没成交"这一反直觉结构；**不得**写成真实成交记录、真实顾客原话
  ——顾客反馈不得虚构（`DIYU-CONTENT-GOVERNANCE-001` §6.3）。
- **本轮修订**：原稿把顾客那句"你没硬推"写进了原句，等于生成虚构顾客原话；v2 已**从原句中移除**，
  只保留阿野自己的动作。若要表达同一层意思，改用下面「第一人称许可」里的通用表述。
- **允许账号**：`S04`。
- **单次 / 可重复**：**单次**。
- **第一人称许可**：允许以阿野口吻叙述自己的动作；顾客的反应**不得引号化**，只能改写为"没有被硬推，是很多家庭到店时的基本期待"这类通用表述。
- **禁推断项**：不得推出成交率、客单价；不得把这句改写后的表述再倒写成真实评论。

## 3 使用总闸

发布任何一条前，必须同时通过：

1. **人物边界**（`DIYU-CONTENT-GOVERNANCE-001` §十四 发布前审核门）："没有虚构真人经历"——
   本库全部条目未绑定真人，凡以真人身份叙述即不合格。
2. **顾客边界**：涉及顾客的一律匿名化，不得出现虚构的评论原句（§6.3 明令"虚构的评论原话"禁止）。
3. **儿童边界**：不得出现儿童姓名、学校、住址与可识别信息，不得以儿童制造家庭焦虑。
4. **组织边界**：`PS-S02-*` 只属杭州店，`PS-S04-*` 只属成都店，**两组之间不得互相借用**。
5. **人名边界**：`PS-S04-*` 的叙述主体「阿野」是演示虚构人名，**不得**在任何内容中被表述为真实员工，也不得为其补写从业年限、学历、家庭情况或销售业绩（`DIYU-CONTENT-ROLE-001` §十二）。
6. **单次条目登记**：`PS-S02-05` 与 `PS-S04-03` 为单次授权，用后即在本表标注"已消耗"，
   对应 `07-异常样本包.md` 第 7 项"私人经历单次授权"演示。
