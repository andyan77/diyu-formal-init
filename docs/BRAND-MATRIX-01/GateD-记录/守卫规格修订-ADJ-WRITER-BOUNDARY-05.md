## 机器阻断边界

机器只阻断可近零误报识别的肯定式组合：

- `保证 + 性能词`；
- `100% + 性能词`；
- `永不／绝不 + 性能词`；
- `绝对 + 性能词`。

成分比例、价格、精确工艺、适穿年龄、已确认事实改值、画像逐字复制和内部商品选择计划照抄
等既有硬门不变。性能词裸提及不再单独触发机器阻断。

## Writer 与人工复核边界

- 未确认性能只允许否定式或边界式提及，例如“不是为 X 设计的”或“如果你要 X，它不是答案”。
- 未确认性能不得写成商品的肯定式能力或保证。
- 成品可见文案只要出现裸性能词，审阅包必须登记卡 ID、命中词和原句；标注不阻断落版、
  不改变卡片二元结果，交由 founder 逐篇复核。

本修订不新增语义检测器，不把审阅标注写入 ProductFact，也不改变旧任务、旧快照或旧 digest。
