# Gate D provider 直连与传输重试政策

- 指令：`UNLOCK-D-RERUN-07`
- 治理来源：主线 `f783c37`
- 状态：执行侧实现稿，待监理复验确认

## 冻结政策

1. DeepSeek／DashScope 境内端点的 HTTP 客户端禁止继承工作站代理环境，以直连发起请求。
2. 正式套件启动前只做 TCP/TLS 握手探针；不发补全请求、不消耗 provider 预算。握手失败进入 `PRECONDITION_BLOCKED`。
3. 内容重试固定为 0。只有连接错误、超时、无响应体 5xx 可在同卡、同请求语义下自动传输重试，最多 2 次。
4. 一旦收到有效内容响应，该卡永不重新请求；不得择优。
5. 每卡账本分别记录语义请求和 `transport_retries`。传输尝试不伪装成新内容请求。
6. 纯传输失败在 2 次重试后仍中断时，仅能在主控明确回复“续跑”后，于同一冻结候选从中断卡续行；已完成卡不重请求。

本文不改变 `temperature=0`、内容重试 0、禁择优、禁跨 SHA 拼接、首次 provider 请求后仅 docs-only 的纪律。
