## 三、最小工程补口

### 3.1 连续系列

- 复用 `content_series`、`content_series_items`、任务版本和既有重放能力；
- 新任务只有在用户明确选择系列时才读取该账号、该系列的必要前情；
- 支持继续下一篇、跳到指定集、在中间补一篇及重排；
- 冻结系列标识、系列修订、目标集次及实际读取的前情版本；V2 只重放任务快照；
- 平台重编译继承源任务冻结的系列前情，但不自动把平台任务加入源系列；
- 普通聊天、浏览、复制、导出、无关生成和失败生成不改变系列；
- 无真实发布记录或用户明确前提时，不得写成受众已经看过上一期。

### 3.2 平台重编译

- 复用 `recompile_task` 和 ADR-015；
- 用户从当前版本选择“另做平台版本”，明确选择目标平台载体；
- 源版本保留，目标账号、平台、媒体、制作条件、源画像与系列前情冻结；
- 服务端按正式会话和明确载体解析作用域，不再按同渠道账号名称排序隐式取第一条；
- 只创建本次需要的单个载体关系，不建设账号组、矩阵、发布连接器或平台 Agent。

### 3.3 真实商品事实

- 复用 `brand_products`，只新增本轮 1—3 件真实商品所需的人话入口和版本/来源元数据；
- 每件商品至少包含自然名称，以及任务真正需要的品类、颜色、材质或结构、轮廓、可观察特征；
- 记录租户、品牌、责任来源、当前版本、适用范围和状态；
- 任务冻结实际使用的商品事实版本；修改和平台重编译不得重读后来变化的商品事实；
- 商品匹配只在当前租户、当前品牌合法集合内进行，不依赖固定 `ZX-*`、`DIYU-*` 格式；
- DM01 快照、候选商品文档和视频推断不得自动升级为长期商品事实。

### 3.4 画像、身份与前端

- `inferred` 控制组织继续不授权；
- 总部画像由有资格的真实主体建立；门店人物账号、组织、本人资格与画像由真实主体建立；
- 五段画像沿用 ADR-027，不增加技术字段；
- 自然语言继续是主入口，创作方向面板仍为可选；普通用户只看到成品、自然修改、系列和平台版本；
- 不建设设置页，不展示 P1—P5 编号、GenerationInput、主张分类或运行轨迹。

### 3.5 R/O 边界

- R 是可人工审阅的制作质量：缺顾客、家庭成员、模特、复杂场地或道具时优先省略、替代或降级，
  可替代资源缺失不得让整篇确定性失败；
- O 继续区分当前立场与现实经历：`主张/希望/建议/尊重`可以表达，未经来源的既往询问、讨论、
  观察、服务或执行不得生成；真实本店做法只在本店作用域表达，不扩大为全国政策；
- 硬商品事实、权限、隐私、真人未成年人原件与租户隔离继续失败关闭；
- 不恢复 M6-3 候选，不加样本词表、固定成稿、第二编译器或随机重跑。

## 七、真实停止线

只在以下情况停止：两个真实身份/控制组织/画像无法由有权主体经现有入口建立；没有任何责任
来源可提供最小真实商品；继续必须改变 P1—P5、账号权威、事实边界、租户隔离或里程碑范围；
必须取得密码/MFA/真实平台凭据或做未经授权的破坏性生产操作；同一稳定结构缺陷经一次最小
共享修复仍无法通过，继续只能降低硬事实、安全或隔离边界。

模型首稿瑕疵、可自然形成 V2、可替代资源不足、搜索/趋势失败、无平台表现数据、普通工程问题、
中间只完成一部分或禁用审查 Skill 不构成停止理由。
