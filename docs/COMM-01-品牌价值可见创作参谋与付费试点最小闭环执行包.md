## 二、本里程碑交付什么 / 不交付什么

### 交付（一句话）

让品牌专属数据**在用户创作决策时可见、可确认、可反馈、可衡量**，并以此支撑
"服务辅助的付费设计伙伴试点"进入前的全部演示与度量闭环。

三个阶段：

```text
阶段 A  价值可见最小闭环（试点演示的最低门槛）
阶段 B  生成前确认与轻评审（试点签约前）
阶段 C  结构化制作包（试点中按真实反馈迭代）
```

### 不交付（与外部评估方案的显式差异）

- 不做微服务拆分、不自建图片/视频生成、不做自动发布、不做第二模型评审/模型投票、
  不建通用 Agent 平台（与外部评估一致）；
- **追加不做**：不一次性实现 AdvisorResponseV1 八卡片合同；不建"品牌测试实验室"自动化
  （先用人工 checklist）；不做 30+ 指标全量埋点；content_form 不做 9 枚举（首期 3 个）；
  不把"关闭品牌约束的通用基线"做进产品（仅受控演示脚本）；不建 `CreativeBriefV1` 物理实体；
  不做 UX-04 全量前端重构。
- 本包完成**不证明**：真实付费、真实持续采用、真实发布、平台流量、GMV（见 §十二）。

### A1 · `context_selected` 流式事件与条目级依据（中）

- 内容：服务端完成上下文选择后，新增一个结构化流式事件 `context_selected`，载荷为

  `kind / title / summary / usage_mode / source_label / source_version / impact`。
- `usage_mode` 枚举（采纳外部评估原案）：

  ```text
  direct_fact        直接事实（服务端确定性插入，允许绑定成品位置）
  product_fact       商品事实（确定性编译，允许绑定成品位置）
  expression_guard   表达约束（只声明"本次受其约束"）
  creative_reference 创作参考（只声明"本次参考"，禁止伪造逐句因果）
  account_identity   账号定位
  ```

  选择结果投影，事实基线 §三-3/4 证明信息本已存在于选择阶段）。
