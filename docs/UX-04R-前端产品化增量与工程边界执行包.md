## 一、定位：替代 UX-04 全量重构的增量方案

外部评估的 UX-04 方案（九子项）实质是一次前端大爆炸重写：目录整体重构、两大巨文件
拆分专项、全局设计系统重建、管理端信息架构全量重排。对一个 2—3 租户试点前、
拥有 9,311 行前端测试资产的产品，该方案的代价与风险不成比例。

本包采用**绞杀者模式（Strangler Pattern）**：新功能一律按新结构落地，旧代码只在被
本包功能触碰时顺势拆出，存量不做专项重写。逐项处置对照：

| 外部评估 UX-04 子项 | 本包处置 |
|---|---|
| UX-04A 信息架构与设计系统 | **缩减**：只做 §五 最小设计规则 + 触碰路径应用；不做全局重建 |
| UX-04B 今日工作台与首次使用 | **采纳（缩减）**：FE-05，消费既有 opportunities 能力 |
| UX-04C 创作参谋工作台 | **缩减**：首期由 FE-05 机会卡 + FE-08 确认卡承接；独立参谋对话页不立项 |
| UX-04D CreativeBriefV1 | **不立项**（COMM-01 D-COMM-04）：FE-08 确认卡承接 |
| UX-04E ProductionPackageV1 | **缩减**：FE-09 渲染已有结构化 Bundle；十节全量合同不立项 |
| UX-04F 品牌依据与知识反馈 | **采纳**：FE-06 |

## 三、工程基础项（FE-01—FE-04）

### FE-01 · 正式路由与懒加载（中）

- 内容：引入路由器（react-router 或等价轻量实现，Brief 阶段定）替换 `Root.tsx` 手工
  pathname 判断；业务应用按路由懒加载；账号/平台切换改为**应用内状态切换**，

- 验收：① 切账号/平台不再整页刷新、编辑器草稿不丢（浏览器测试断言）；
  ② 全部既有 URL 路径向后兼容（逐路径对照表附于 PR）；③ 首包体积不增（懒加载生效证明）。

- 验收：新代码零手写 API 类型；`scripts/golden.sh` 漂移检查扩展覆盖前端生成产物。

### FE-03 · 死样式清理（轻）

- 验收：全 TSX grep 零引用证明附于 PR；多视口截图回归无差异。

### FE-04 · 测试资产保护（硬约束，贯穿）

- 内容：9,311 行前端测试（含 7 个浏览器脚本）为本包全部改动的硬约束——保持通过或

## 四、产品界面项（FE-05—FE-11，与 COMM-01 工作项一一对应）

### FE-05 · 今日工作台首屏（中；承接 COMM-01 A3）

- 内容：替换"今天想说什么？+ 空输入框"冷启动。首屏自上而下：
  ① 起始入口行（帮我找选题 / 评估一个想法 / 直接制作 / 了解笛语）；
  ② 推荐机会卡 2—5 张（标题 / 推荐原因 / 创作方向 / 相关素材 / "用这条开始"），
  消费 `POST /api/v1/content/opportunities`；
  ③ "继续进行"（内容计划 + 最近成品）；
  ④ 品牌上下文摘要一行（可用事实/边界/方法/商品事实计数 + 当前缺口）。
- 边界：浏览/刷新/保存计划不建立任务（后端契约已存在）；"用这条开始"只回填输入区
  与方向，不直接生成。
- 验收：① e2e 复证三表计数不变；② 未选账号优雅降级；③ 无空白画布状态
  （加载失败时也有可操作入口）。

### FE-06 · 品牌依据常驻面板与反馈入口（中；承接 A1/A2/A6）

- 内容：依据面板由 `<details>` 折叠改常驻。生成前显示"本次已锁定 N 项品牌依据"
  （消费 `context_selected` 事件）；生成后条目级展示：类型（usage_mode 五分类的用户可读
  文案）、标题、本次作用、来源版本、缺口；每条目带反馈入口（错误/过期/无关/缺失 →
  `brand_basis_feedback` 通道）。
- 诚实边界：只有 `direct_fact` / `product_fact` 可展示成品位置绑定；`creative_reference`
  只显示"本次参考"；面板内禁止出现 segment ID / digest / FT / SHA。
- 验收：① 不展开任何折叠即可见；② 载荷 grep 断言无内部 ID；③ 移动端双工作面下均可达；
  ④ 反馈提交后有回执且不可撤销覆盖。

### FE-07 · 帮助与诊断三级分流（轻；承接 A4）

- 内容：`CapabilityGuide` 从 `/user` 撤下，移至管理端"技术诊断"二级入口；普通用户帮助
  改任务导向四问（能做什么 / 本次会用什么 / 缺什么 / 怎么完成）。
- 验收：`/user` 渲染结果 grep 无 `FT-`/`SHA`/`Schema`/"58 项"；管理端诊断保留全量。

### FE-08 · 生成前确认卡（中；承接 B1，依赖其后端）

- 内容：提交创作输入后渲染确认卡：主题理解 / 系统选定方向 / 平台与形式 / 将使用依据
  N 项 / 将不写入事项 / 至多一个可跳过的策略选择问题。主动作"按此制作"；次动作
  "修改一次 / 跳过问题采用建议"。页面顶部阶段指示：`确认中 → 正在制作 → 成品`。
- 交互约束：熟练路径一键确认，摩擦增量恰为一次点击；"发送 / 生成内容"双按钮心智
  由此收敛（发送=交流，生成=进入确认卡）。
- 验收：① 确认前三表计数不变；② 策略问题 100% 可跳过；③ 浏览器测试覆盖
  "确认 / 修改 / 跳过"三分支。

### FE-09 · 结构化制作包渲染（中—重；承接 C1，依赖其后端）

- 内容：成品页按结构化 Bundle 字段渲染（视频：总览 / 台词 / 字幕 / 制作提示 / 发布配文
  分节；图文：页序结构；DM01：结构化执行表但保持文字方案定位），**删除 `ArtifactBody`
  正则猜标题与 DM01 `PlanText` 换行猜测**。宽表在自身容器内横向滚动；移动端每节段
  转纵向卡片。
- 诚实边界：无真源字段（音效/景别/转场）若后端未提供则不渲染占位，不得前端补造。
- 验收：① 新成品零正则启发式；② 旧成品 body 字符串兼容回退渲染；③ 节段级复制/导出可用。

### FE-10 · 采用与评审操作区（轻—中；承接 A5/B2，依赖其后端）

- 内容：成品操作区增加"标记采用 / 导出 / 放弃"（A5 事件）；B2 上线后增加
  "批准（含批准人时间）/ 已人工发布（可选 URL 回填）"。
- 验收：操作全部落事件/状态且有界面回执；无自动发布入口。

### FE-11 · 首页动效非阻断化（轻）

- 内容：7.2 秒阻断动效改为非阻断——品牌主张与"开始创作"入口与动效同时可见可交互；
  动效降级为陪伴性转场；`prefers-reduced-motion` 直接静态呈现（现有支持保留）。
- 验收：入口在首帧即可交互（浏览器测试断言 `pointer-events` 与可见性）；跳过路径保留。

## 五、最小设计规则（只约束本包触碰路径）

> 不做全局重新皮肤。以下规则自本包起对**新增与被触碰**的界面生效，存量不回刷。

1. 保留品牌资产：暖白纸张 / 墨色正文 / 朱砂强调 / 宋体标题 / 克制阴影。
2. 朱砂只用于：唯一主动作、当前选中、品牌依据强调、高价值提醒；新增语义色：
   确认-绿 / 待补-琥珀 / 错误-深红 / 信息-蓝灰（token 化，双主题可用）。
3. 字号下限：正文 16px / 辅助 14px / 元数据 12px；修复 `0.62rem` 两处全视口过小标签。
4. 圆角：主按钮胶囊；普通按钮 10—12px；卡片 14—16px；筛选标签才用胶囊。
5. 触控目标 ≥44px、键盘焦点样式、减少动效支持——沿用现有基础，不倒退。

## 六、验收旅程（本包放行条件，真实用户任务为单位）

| 旅程 | 必须成立 |
|---|---|
| 首次进入 | 未受训用户在 `/user` 首屏能辨认：找选题 / 评估想法 / 直接制作 / 了解系统；无空白画布；无工程自证术语 |
