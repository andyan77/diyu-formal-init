## 1. 阅读口径

精简 V1 恰有 25 项：21 项默认可见，4 项体型相关方向只有本人主动启用后才出现。“进入正式
UI”只表示它可以作为**可选创作方向**进入既有消费者，并且有至少一种可复核证据；不表示每个
组合都经过真实租户采用，也不表示用户选择后可以绕过商品、人物、素材或外部来源条件。

- `verified`：当前范围已有直接实现与验收证据，可以按既有边界进入。
- `composable`：已有明确消费者、边界和可复核证据，可以作为组合方向进入；它仍不是一项经过
  独立真实试点的稳定市场承诺。
- `supporting_asset_ids` 为空，只表示目录真源没有直接 `system_domain_assets:*` 引用，不自动
  等于不支持。
- “运行消费者”中的共同主链为
  `ContentControlService.catalog_view / resolve_request_direction`
  → `GenerationInput.creative_direction` → 当前内容生成适配器；表格只补充各项特有消费者。
- 表中的 H1/H2/H3/S1/S2/S3 版本均以
  `docs/M7-2B-演示内容验收索引.md` 为人读入口；测试名称均位于表中所指向的既有
  `tests/test_*.py`，本文没有新增或重跑测试。
- UI-03 已由 `frontend/src/app/CreatorApp.tsx` 从
  `/api/v1/content/expression-catalog` 动态消费 24 项内容主链方向；目录条目没有在 React
  硬编码。`frontend/test/interaction.test.tsx` 与
  `tests/test_ui03_react_content_mainline.py` 提供 21 项默认可见、4 项体型主动启用、未支持项
  不可见/不可建半任务、合法素材选择和正式 API 快照证据。连续系列的完整对象旅程仍由 UI-04
  承接。精简 V1 没有一项以 F10 为当前去向。
- UI-03 没有改变生成 Prompt、模型适配器或运行资产选择，未重新调用 DeepSeek；风格、题材、
  体裁与透明转译的真实语义结果继续引用 M7-2B/M7-3 已关闭证据，本轮新增的是正式 React
  消费者、可信 API/数据库链和交互反证。
