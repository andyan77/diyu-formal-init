# 能力缺口与补全清单 V1

> 本清单是 `config/content_expression/capability-inventory-v1.jsonl` 的人读整理，不是待办
> 状态机。每项仍以稳定 ID、当前状态和既有 F 项去向为准；只有真实消费者触发后才补。

## 阅读口径

- “缺口”包括缺来源、缺租户事实、缺真人/现场素材、缺平台工具、缺创作方法、政策冲突和
  原始目录缺失；它不都意味着需要写代码。
- 商品、人物、事件和门店现场由相应租户责任来源提供，不伪装成领域通用知识。
- “是否需要发版”区分**本次任务补资料**与**把目录状态升级为长期能力**。后者至少需要
  一个版本化目录/资产变更；前者在现有合法入口可承接时不要求代码发版。
- 39 项缺口视图中的 `CAT-STYLE-FORWARD-04` 同时属于 6 项实验能力。它是同一稳定 ID 的
  两种观察角度，不重复计为两个能力。

## 十、对账结论

- 39 项缺口视图：完整，稳定 ID 无缺失。
- 6 项实验能力：完整；其中“语气指纹”与创作方法缺口是同一 ID 的交叉视图。
- 1 项明确不做：到店核销，继续留在 F06。
- 38 个 `unsupported`、6 个 `experimental`、1 个 `explicitly_out_of_scope` 的机器状态
  仍以 119 行真源为准；本清单没有手工升级任何能力。
- 租户商品、人物、事件、平台连接器与现场素材均回到各自责任来源和真实消费者，不被包装
  成系统通用知识。
