# 笛语内容生成能力双层模型与质量增强指南 V1.1

状态：第一阶段交付后的质量增强依据  
版本关系：V1.0 原样保留为历史；V1.1 增加资产总账、目录缺口与产品呈现纪律，不代表新增能力已经实现

## 1. 不变的双层模型

内容质量继续由两层共同形成：

- A 层：系统稳定能力。包括有真源、有适用范围、有消费者并经过相称验证的知识和方法；
- B 层：当前对象与任务。
  - B1 是品牌、发布账号、账号定位和长期协作关系；
  - B2 是本次真实种子、商品、素材、系列前情、平台和制作条件。

一次好成品来自 `A × B1 × B2` 的真实组合。A 层不能替品牌、商品或人物编事实；B 层资料存在也不代表系统已经具备对应方法或平台能力。

## 2. 资产与能力不能混算

当前人类可读入口是 [能力资产台账](能力资产台账/README.md)，其真源仍是仓库内 JSON/JSONL。

| 家族 | 当前事实 | 能证明什么 |
|---|---:|---|
| 语义模型 | 25 类 | 领域数据的结构分类 |
| 系统资产候选 | 243 条：99 知识、58 方法、8 角色模板、78 评测规则 | 已登记的机器可读候选 |
| 运行激活 | 41 条：20 知识、21 方法 | 已有明确消费者与适用范围 |
| 夹具候选 | 123 条 | 可用于评测设计的候选；其中当前 4 条绑定自动测试 |
| 内容目录位置 | 119 个：116 有定义、3 个源缺口 | 原始风格/题材/体裁的完整位置账 |
| 精简目录 | 25 项：默认 21、体型主动启用 4 | 普通创作面板的首期展示集合 |
| 平台媒体目标 | 4 个 | 当前受支持的媒体目标类型 |
| 品牌候选资料 | 18 份 | 笛语品牌资料候选，不等于生产事实 |
| VI 真源文件 | 36 个 | 正式视觉资产，不等于内容能力 |
| UI-01 历史页面 | 19 张 | 页面覆盖盘点，不等于产品方向已通过 |

这些资产家族不能相加后宣称“系统共有多少项能力”。候选登记、运行激活、本次实际调用、已验证能力和真实租户采用是五层不同证据。

## 3. 内容表达目录的诚实边界

目录位置对账为：

- 风格 `20/20`；
- 题材 `55/55`；
- 体裁 `41/44`；
- 三个体裁来源缺口保留稳定 ID，不猜补标签。

能力状态为：

- `verified` 10；
- `composable` 64；
- `experimental` 6；
- `unsupported` 38；
- `explicitly_out_of_scope` 1。

普通页面只展示精简 25 项，其中 21 项默认可见；显高显瘦、小个子、微胖梨形、苹果型 4 项只有用户主动启用体型相关方向后出现。目录位置不等于已支持能力，精简展示也不等于全量目录被删除。

## 4. 缺口如何进入增强

[能力缺口与补全清单](能力资产台账/能力缺口与补全清单_V1.md)按稳定 ID 保存 39 项缺口记录、6 项实验能力和 1 项明确不做。语气指纹同时属于创作方法缺口和实验能力，两个视图不能机械相加。

增强时按缺口本质路由：

- 可信知识或来源：补有责任人的来源、版本与时效，不拿租户事实代替；
- 商品/经营事实：由租户有权事实来源提供，经既有作用域使用，不沉淀为领域通用知识；
- 真人/现场/素材：由素材权利人和真实场景提供，不通过模型补造；
- 平台/媒体/工具：在出现真实消费者后另立有界能力版本，不用平台黑箱权重冒充；
- 创作方法：先证明跨任务共享根因，再形成版本化方法；
- 政策冲突：保持责任边界，不能靠增加知识绕过；
- 原始目录缺失：只能由研究真源补齐标签后发布新目录版本；
- 明确不做：到店核销保持独立交易合同，不混入内容能力。

## 5. 从资产到一次生成

每次生成只选择当前任务必要的最小能力组合：

1. 先解析账号位置、受众回报和任务目标；
2. 再判断是否需要商品、场景、系列或平台事实；
3. 只在适用条件成立时选择已激活知识或方法；
4. 把本次使用的对象版本和前情冻结到既有任务留痕；
5. 输出完整成品，让后台约束静默成立，不把防错说明机械复述给用户；
6. 内容不自然时优先由用户自然修改，不用随机重跑或样句补丁碰运气。

`active` 只说明资产具备运行消费者，不能推断每次生成实际使用。实际调用仍需看本次运行留痕。

## 6. 产品呈现纪律

资产台账、稳定 ID、能力状态、依赖、评测引用和内部边界不进入普通创作页面。用户看到：

- 当前账号与平台；
- 自然输入和可选创作方向；
- 一段自然概要；
- 标题、完整正文/台词、制作说明和发布辅助；
- 继续修改、平台版本和历史版本；
- 一句自然的使用提醒。

如果某个方向暂不具备所需事实或工具，页面说明当前缺什么和可做什么，不展示内部分类报告。

## 7. 质量增强的触发门

只有出现以下证据，才把候选推进到稳定能力：

- 有清楚、重复出现的用户任务；
- 有合法事实或来源；
- 有直接消费者和适用范围；
- 有代表性成品或夹具证明主要结果；
- 有失败边界和退场条件；
- 不降低事实、隐私、账号身份或租户隔离。

真实发布、平台流量、排名、爆款、销售和企业采用只能由真实使用证明，不能由候选数量、模型自评、静态原型或自动测试替代。
