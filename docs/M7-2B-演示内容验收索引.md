# M7-2B 演示内容验收索引

本索引是给产品验收者看的稳定导航，不是第二套内容库或里程碑状态机。完整正文、旧版本和当前
版本均从正式生产对象实时读取，入口为：

> https://diyuai.cc/tenant-admin?section=demo

未登录时会先进入租户管理员登录；登录成功后直接返回“演示内容验收”。页面中的演示操作者没有
共享密码。租户管理员可为某一演示操作者生成一次性安全进入链接，由本次验收者设置自己的独立
密码后进入内容工作台。该动作不连接抖音、小红书或微信视频号，也不索取平台凭据。

## 三、商品承重结果

| 内容 | 人话价值 | 有界结论 |
|---|---|---|
| S2 当前 V4 | 先按“各自舒服”或“画面统一”的本次目标给条件性建议，再让固定手机前的创作者逐件持衣进入/退出画面，各录一段并按本次目标回看 | 通过选择帮助门；删除了与实际动作不一致的“两件商品同框改变位置”承诺，不要求顾客或一家三口演员 |
| H2 当前 V13 | 教受众先看完整外套轮廓、牛角扣和学院外套结构，再把面料、厚薄和保暖等性能留给商品资料 | 通过商品解释门；是一人、固定手机、始终持衣的对外成品 |

有界复核没有把旧 H3 V1 继续算绿：V1 只改变商品在取景框里的露出面积，没有充分建立新的
穿着可能。系统沿同一正式任务自然修改到 V6，V1—V5 保留；V6 把方向收成可真实执行的
“克制冷幽默＋多图合集”，三张静态画面始终展示两件完整商品，靠同平面同距离下的等权、白色
居中和亮黄居中形成配色主次。去掉三张商品关系后 P5 主价值随之消失；它仍不证明真人穿着后的
合身、上身效果或销售结果。

## 五、点名反证

- S2 当前 V4 全文与动作中没有桌子、桌面、纸、纸笔、笔或马克笔；手机先固定，创作者逐件
  持衣进入和退出画面，各录一个可回看片段。台词不再承诺同框改变两件商品的位置，不同时拿
  手机与两件衣服，也不需要顾客、儿童或一家三口演员。
- 历史上曾有一条已脱离当前系列的失败候选加入桌面、白纸和马克笔；它没有被删除或伪装成通过，
  但不进入本索引的六篇当前系列，也不作为 S2 当前版验收证据。
- 总部 H1 与门店 S1 即使去掉账号名称仍不同：总部提出可供品牌采用的当前立场，门店只说个人
  在假设处境中的理解与建议，并明确不是本店已经执行的服务。
- S3 当前 V7 只出现一名创作者、一部先固定且全程不移动的手机、空墙、自然呼吸和停顿；不要求
  三脚架、台面或其他固定设备。它从“对方尚未表示需要时先看清浏览节奏”承接门店系列，全部
  使用假设与本人当前理解，没有顾客、商品、真实关店事件、励志化或品牌宣言。
- H2 当前 V13 无桌面、平铺、字卡、吊牌、详情页或未登记的具体结构部位，完整口播只给受众

  当前 V6 的三张静态画面、多图合集方向和轻微冷幽默互相一致。
- 总部小红书当前任务 `d8fbe92b-d43a-42ae-9dd8-5914bb87ab7b` 的源为 H3 V6；当前版只有一套

  `a1221b91-3f14-4471-9c2f-3c946081061e` 使用同一 H3 V6 父版本，当前版本为

## 六、人工审查结论

- 审查 A（用户成品与市场竞争基础）：`PASS`。六篇未退化为同一模板；两种身份同题观察位置
  有实质差异；S2 V4、H2 V13、H3 V6 分别通过选择帮助、商品解释和可见造型门；旧 H3 V1 的
  错误绿灯已撤销；S2/S3 的当前制作条件可执行，总部三平台保持同一 P5 核心但标题、开头、
  结构和媒体组织实质不同。
- 审查 B（事实、作用域和回写）：`PASS`。演示商品来源和版本可追溯；没有把模拟人物、经历、
  顾客、门店做法、设计动机、性能、价格、库存或在售状态写成真实事实；账号、画像、系列、
  商品、私人偏好与素材未串用；失败不产生半版本；AIGC 披露、FORCE RLS、跨租户失败关闭与
  无知识/目录/画像/偏好自动回写成立。

两份审查只判断当前软件与演示成品，不承诺真实人员采用、真实商品采用、发布、流量、排名、
爆款、GMV、销售、企业采用、多个真实租户之间的市场差异化或企业 SLA。

## 七、用户实际看到和转移的内容

生产正文仍完整保留内部事实、账号、方向和产品门数据，但普通页面、历史版本、演示验收索引、
复制和导出统一使用同一服务端人话投影。用户看到的是：

1. 自然语言内容概要；
2. 标题；
3. 完整台词、解说或发布正文；
4. 必要的画面、动作、字幕和声音制作说明；
5. 发布配文及平台辅助内容；
6. AIGC 自然提醒。

`账号观察/受众获得/账号关系/演示商品锚点/可见造型命题/画面成立条件` 等编译脚手架不进入
上述口径。上一轮生产全量只读扫描的 37 份源、历史和平台可见版本全部干净；本轮又从同一正式
管理 API 定向复核 S2 V4、S3 V7、H3 V6 及新的总部小红书/视频号 V2，人话投影未回退。复制
和导出继续追加同一 AIGC 披露，不从存储正文重新暴露被隐藏字段。

一次性演示进入继续由租户管理员在验收页为对应演示操作者生成。新链接自动失效旧链接，成功
使用后同一用户的其他链接和旧会话一并失效；HTTP/HTTPS Nginx 与应用日志不记录原始 token。
正式路由和维护路由合计四个 `/activate/` location 均在位置级关闭 access/error token 日志并
返回 `Referrer-Policy: no-referrer`；HTTP 入口固定跳转到 HTTPS 首页，不携带原始
`$request_uri`。本轮只用明显测试夹具假 token 做了一次生产反证，access/error/app 三类日志
原文命中数为 `0/0/0`；未读取或输出真实 token。
系统不提供共享密码，不连接平台，也不要求先填真实个人或企业资料。
